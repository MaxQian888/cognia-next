# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Project Overview

Next.js 16 (React 19) + Tauri 2.9 + Capacitor 8 + TypeScript + Tailwind v4 + shadcn/ui + Zustand. One static export (`out/`) feeds three shells: browser (`pnpm dev`), Tauri desktop (`pnpm tauri dev`), Capacitor mobile (`pnpm mobile:sync`).

## Working Rules

Hard rules. They override any default behavior. The end-to-end pipeline (idea → brainstorm → grill → plan → build → preflight → gates) lives in [`WORKFLOW.md`](./WORKFLOW.md). Follow it for any non-trivial change.

1. **Research before implementing.** Search `lib/`, `components/`, `hooks/`, `src-tauri/`, and the relevant ADR before writing new code. Reuse, don't reimplement. A new utility/component/hook needs proof (grep results or paths) that no equivalent exists. Start with the Subsystem Map and Cross-cutting hooks below.
2. **No simplifications.** Implement the full behavior. No stubs, mock-outs, `// TODO later`, or stripped error handling / validation / edge cases. If something cannot be implemented now, surface the blocker. Never silently degrade scope.
3. **Every component ships with a unit test.** Any new file under `components/**`, `hooks/**`, `lib/**`, `src-tauri/src/**`, or `web/{components,hooks,lib}/**` (excluding `components/ui/`, `components/ai-elements/`, `web/components/ui/`) needs a co-located `*.test.ts(x)` / in-file `#[cfg(test)]`. Enforced by `pnpm audit:colocated-tests`. Editing an existing component? Update its tests in the same change.
4. **Every frontend component is i18n-wired.** No hard-coded user-facing strings in `.tsx` (aria labels, placeholders, toasts, and error messages count). Use `useTranslations()` / `getTranslations()` from `next-intl`. Add keys to the **split sources** `i18n/messages/{en,zh-CN}/**` for both locales, then run `pnpm i18n:build`. The aggregates `i18n/messages/{en,zh-CN}.json` are generated, never hand-edited. `pnpm lint:i18n` checks parity against the baseline.
5. **Language convention.** Internal narration (status updates, rationale, summaries, code comments) in **English**. Questions to the user (clarifications, `AskUserQuestion`, confirmations) in **Chinese**.
6. **Changeset for every user-facing change.** Run `pnpm changeset`, select **`cognia-next`**, pick the bump (`patch` fix / `minor` feature / `major` breaking), write a one-line summary, and commit the `.changeset/*.md` with the code. Skip only for internal-only work (tests, refactors, docs, chore, CI). Release is local-only: `pnpm release:version` bumps the root version, updates `CHANGELOG.md`, and syncs every app artifact via `version:sync`. Only the root is Changesets-managed. Do not add a publish step or release Action without asking.
7. **Label intentional dormancy on all three axes.** Documented at the type, labeled inert in the UI, and pinned by a test. Any two of three is a latent bug.
8. **The working tree is shared. Only touch your own changes.** Several sessions edit this checkout concurrently. Every git command names explicit paths this task modified.
   - **Commit** with `git commit --only <paths>` or `git add <paths> && git commit`. Never `git add .` / `-A` / `-u`, `git commit -a`, or stage a whole directory.
   - **Never run tree-wide state commands**: `git stash` (any form), `git checkout -- .`, `git restore .`, `git reset --hard`, `git clean`, `git rebase`, `git merge`, `git revert`, branch switches. They destroy other sessions' uncommitted work.
   - **Need a clean view?** `git show HEAD:<path>`, `git diff -- <path>`, or a separate `git worktree add`. Never reset this one.
   - **Before committing**, check `git diff --cached --name-only` and drop anything you did not author. A gate failing on someone else's file is pre-existing. Report it and move on.
   - **`--no-verify` is banned.** A failed hook means fix your own files and make a new commit.

## Development Commands

```bash
# Frontend (port 3000)
pnpm dev / build / start / lint / lint:fix / format / format:check / typecheck

# Jest (co-located *.test.ts(x)); two projects: pure-.ts suites under
# lib/stores/cli/packages/types/plugins/i18n run in `node`, everything else
# (and any `/** @jest-environment jsdom */` .ts, needed for Dexie/getDb,
# localStorage, window stubs) runs in jsdom
pnpm test / test:watch
pnpm test:changed            # only suites affected by your diff vs origin/dev
pnpm test -- path/to/file.test.ts

# Playwright E2E (tests/e2e/)
pnpm test:e2e                # against the dev server
pnpm test:e2e:build          # NEXT_PUBLIC_E2E=1 static export → out/
pnpm test:e2e:static         # against the prebuilt out/ (run test:e2e:build first)
pnpm test:e2e:changed        # only specs affected by your diff vs origin/dev

# Shells
pnpm tauri dev / build / info
pnpm mobile:sync / mobile:open:ios / mobile:open:android   # after `pnpm build`

# Docs (Fumadocs, port 3001) / Marketing site (port 3002, ADR-0092, `@web/*` alias, not `@/`)
pnpm docs:dev / docs:build / docs:start
pnpm web:dev / web:build / web:start / web:evidence / web:capture / web:test:scripts

# Gates
pnpm audit:colocated-tests   # co-located test rule
pnpm audit:slots             # plugin slot manifest audit
pnpm lint:i18n               # i18n key parity vs baseline (lint:i18n:baseline rewrites it)
pnpm i18n:build              # regenerate en.json / zh-CN.json from split sources (`:check` to verify)
pnpm sidecar:test            # node --test on sidecar/ (separate Node project, not Jest)
pnpm build:packages          # standalone tsup build of the zero-`@/` packages; run after ANY
                             # types-shim extraction: a child tsconfig's `paths` REPLACE the root's

# shadcn/ui ("new-york", RSC)
pnpm dlx shadcn@latest add <component>

# Storybook (preview only: stories are NOT tests and don't satisfy Rule 3)
pnpm storybook / build-storybook
```

`predev` / `prebuild` stage bundled assets (Monaco, OCR, built-in plugins/skills, sidecars) via `scripts/build/*`. Never copy or import those assets by hand. The Storybook MCP server in `.mcp.json` only works while `pnpm storybook` is running.

## Architecture

| Package  | Path      | Port | Mode                                                        |
| -------- | --------- | ---- | ----------------------------------------------------------- |
| Main app | `/`       | 3000 | static export (`out/`), consumed by Tauri **and** Capacitor |
| Docs     | `docs/`   | 3001 | static export (`docs/out/`, Fumadocs), Cloudflare Pages     |
| Website  | `web/`    | 3002 | static export (`web/out/`), Cloudflare Pages                |
| Mobile   | `mobile/` | none | Capacitor 8 shell over `../out`                             |

Install from repo root only (single `pnpm-lock.yaml`). `sidecar/` is a separate Node project with its own lockfile, not a workspace member.

- `app/` App Router, static-exported. `app/api/` does **not** exist at runtime. Anything needing an HTTP server lives in Tauri Rust (axum).
- `components/ui/` shadcn (no tests). `components/ai-elements/` vendored (no tests). `TooltipProvider` is mounted in `app/layout.tsx`.
- `lib/utils/index.ts` (`@/lib/utils`): `cn()` = clsx + tailwind-merge.
- `i18n/`: next-intl via `withNextIntl("./i18n/request.ts")` in `next.config.ts`. Split sources under `messages/{en,zh-CN}/`, aggregates generated.
- `plugins/`: in-tree first-party plugins loaded by the plugin manager, not npm packages.
- `sidecar/`: Node sidecar bundled by Tauri (`claude-host.mjs`, `dispatch/`, `builtin-tools/`).
- `src-tauri/`: Rust backend, `frontendDist: ../out`. Shared crates under `crates/`.
- `docs/`: import `@/lib/source` and `collections/server` (alias → `.source/`, generated by `pnpm docs:dev` / `docs:build`).
- Styling: Tailwind v4 via `@tailwindcss/postcss`, oklch CSS vars in `app/globals.css`, class-based dark mode (`@custom-variant dark (&:is(.dark *))`).
- Aliases: `@/*` → repo root. `@cognia/*` → `packages/*/src`. `@web/*` inside `web/`.

## Testing Standards

- **Co-located** `xxx.test.ts(x)` next to source. No `__tests__/` or `tests/` directories. Pre-existing gaps live in `scripts/gates/colocated-test-baseline.json` and that list may only shrink.
- **Rust**: in-file `#[cfg(test)] mod tests`. Integration tests in `src-tauri/tests/` allowed.
- **Excluded**: `components/ui/`, `components/ai-elements/`, `web/components/ui/`, `web/app/`, `web/content/`.
- Which runner owns what is in [`CI_CD.md`](./CI_CD.md).

## Commit Hooks

Husky via the root `prepare` script. `pre-commit` → `lint-staged` (eslint --fix + prettier) and `lint:i18n:staged`. `commit-msg` → commitlint (Conventional Commits). Never `--no-verify`. A failed hook means fix the root cause and make a **new** commit.

## Critical Notes

- **pnpm only**, from repo root.
- **Never remove `output: "export"`** from `next.config.ts`. Tauri and Capacitor consume `out/`. `docs/next.config.ts` is a separate static export.
- **Dexie schema is ONE version, not a chain**: `lib/db/schema.ts` declares the whole store set as `CURRENT_SCHEMA` at `CURRENT_SCHEMA_VERSION` (currently **v225**). No `version(N)` chain, no `upgrade()`. To change it: edit `CURRENT_SCHEMA`, **bump the version** (an un-bumped edit is silently ignored on existing databases), add the table to `CORE_TABLE_NAMES` in `lib/data-governance/table-catalog.ts`, run `pnpm db:governance:write`. Drop a table by setting it to `null`, never by deleting the key. A mismatched `storageLayout` marker is refused at boot and routed to an explicit reset. Local data is not migrated.
- **Native vector store**: sqlite-vec at `<app_data>/cognia/vectors.sqlite`. Web mode forces cloud.
- **Rust toolchain**: 1.95 (`rust-toolchain.toml`).
