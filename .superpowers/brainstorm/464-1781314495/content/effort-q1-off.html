Open question #1

The current CLI has six levels: off, low, medium, high, xhigh, max. The reference image starts at low and has no off. How should off be handled?

A

Remove "off"

Minimum slider position is low. The model always gets an explicit effort.

B

Keep "off" as a toggle

Add a checkbox/row above the slider for "Use model default (off)". When checked, the slider is disabled.

C

Keep "off" separate

Slider shows low→max only. off stays in config but is set elsewhere (e.g. /config menu), not this overlay.
