Open question #2

Reference图最右侧的 ultracode 标注为 xhigh + workflows。它应该是什么语义？

A

New thinking level

把 ultracode 加入 THINKING_LEVELS，作为 max 之后的一个等级；内部映射到 xhigh effort + 自动启用 workflows。

B

Composite mode flag

新增独立配置 ultracode: boolean。开启时：thinkingLevel 锁定/显示为 xhigh，并启用 workflows；关闭时回到普通滑块。

C

UI shortcut only

ultracode 只是滑块最右端的视觉标签；选中 max 时按 > 再切到 workflows-on 状态，不新增持久化字段。
