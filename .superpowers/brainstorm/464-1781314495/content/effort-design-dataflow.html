State transitions

  • Initial overlay: derive off from config.thinkingLevel === "off"; derive index from current non-off level.
  • Toggle off: checkbox on → index resets to last non-off level (or default low); checkbox off → level becomes "off".
  • Move slider: if off was checked, auto-uncheck it.
  • Confirm (Enter): compute level from off/index; pluginTools = level === "ultracode"; dispatch SET_THINKING { level, pluginTools }; persist both keys; drop session so next turn picks up new options.
  • Cancel (Esc): close overlay, no state change.
