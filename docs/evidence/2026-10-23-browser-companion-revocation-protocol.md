## Problem frame

Fix O1/O2/O3/O4/O5 while preserving C1. Cancellation must reach pending permissions and
later browser API boundaries; an already-dispatched Chrome API cannot be recalled.
Driving requires a negotiated safety profile and compatible overlay, while legacy
peers may continue capture/status. Repository extraction, package publication,
store release and unrelated rich-capture features remain outside this change.
