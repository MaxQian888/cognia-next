## Problem frame

The gap to ChatGPT-style adaptive UI is not component count (68 exist) but the
path from model output to a live, two-way surface: while streaming the user sees
raw JSON (O1), a bad fence silently vanishes (O2), clicks in desktop/web chat
never reach the agent although IM/TUI do (O4, O5), derived values cannot be
declared at all (O8, H1), and A2UI URLs bypass the chat URL policy (O9). Solved
when G1 holds with tests pinning each path and the false contract text (O7) is
corrected. Out of frame (Q1): official v0.9.1 adapter (O14), JSON-Schema
contracts for all 68 types (O10), validation feedback to the model (O11), eval
harness, enabling A2UI by default (O12).
