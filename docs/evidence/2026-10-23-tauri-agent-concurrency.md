## Problem frame

G1 requires capability-scoped clients around the existing debug chain. Scope is one owned shared-mode native app, per-session latest refs, app-wide workflow ownership and one executing mutation. Session credentials support cooperating local agents; they do not sandbox a hostile process running as the same OS user. Arbitrary renderer evaluation and persistent dialog/network overrides remain unavailable in shared mode. Legacy single-owner mode stays supported. C1 and C2 determine the implementation and acceptance obligations.

Implementation notes for the completion increment:

- The workspace mutex is a loopback OS socket keyed by canonical workspace. Existing IM TTL/file locks were rejected because stale acquisition can steal a fresh holder or leave an ownerless lock; this is lifecycle coordination only, not a second lease engine. Launch intent precedes spawn; unresolved intent remains fail-closed through both launch and stop. Status is read-only, and failed startup preserves records until tracked processes are confirmed stopped.
- CLI descriptors reuse TauriClientSession, atomic private publication, live identity checking and the same request/lease methods. A missing persisted lease proof is recovered through only that client's native status before release. Owner management never falls back from --client to discovery.
- Expiry/revoke retire credentials and refs under the same manager lock. Retired IDs flow through middleware into the existing helper releaseSession/tombstone path, avoiding native-only capacity reclamation. Old operation/capture/cleanup futures cannot publish or clear new state after recovery.
- Recovery uses existing RendererLifecycle plus reload/eval transport, checks each new document's renderer generation/document epoch/document ID/readiness and empty input, then rechecks the full window set/incarnations before reopening. It rotates the same IdempotencyCache only after all old clients are retired. Failed or cancelled recovery keeps quarantine, and old external effects are never replayed.
