## Support matrix and boundaries

| Area                       | Observed support                                                                                                 | Boundary / gap                                                                                                                                                                                                                                                                   |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Transports                 | stdio, legacy SSE, Streamable HTTP in client seams                                                               | Settings discovery differs from execution.                                                                                                                                                                                                                                       |
| Credentials and governance | SecretRef/keyring, OAuth/PKCE/refresh, pending/trusted/blocked Registry, guarded remote egress, Agent projection | F1/F2 show incomplete reuse across callers; real provider acceptance not performed.                                                                                                                                                                                              |
| Tools                      | Namespaced execution, runtime filtering/gates, retries/timeouts, teardown/stderr logs                            | Discovery pagination and custom-mode selection diverge.                                                                                                                                                                                                                          |
| Resources and prompts      | Gateway read/get APIs; managed external-service mentions/slash commands                                          | `lib/external-services/providers/mcp-chat.ts:155-157` gates projection on managedBy. | MCP Apps                   | Sandboxed frame, approval UX, resource/download helpers, rich-cache tests                                        | Discovery strips the linking metadata (F5); native/browser execution routing remains unverified (X3).                                                                                                                                                                            |
| Tasks                      | `lib/mcp/tasks.ts` has list/get/cancel/result helpers and unit tests                                             | No production import of these helpers or complete task-augmented call flow found; helper existence is not user-visible Tasks support.                                                                                                                                            |
| Server-initiated features  | Elicitation adapters/approval UI exist for SDK and external runtime events                                       | Shared transport's onElicitation callback has no production supplier found; AI SDK path uses capability snapshots without an integrated roots/sampling/elicitation/notification loop. Do not apply this statement to SDK-managed Claude features without separate runtime tests. |
| Browser and paired/mobile  | Summary sync, tool rule toggles, explicit reach gating                                                           | Settings discovery is desktop-shell gated. Full capability parity is not promised or established.                                                                                                                                                                                |
| Inbound External Bridge    | Scoped authentication, client-bound sessions, stream endpoint, tool/resource/prompt hosting                      | Same-session response routing F7; no Rust HTTP smoke in this audit.                                                                                                                                                                                                              |

Sampling, roots, elicitation, and Tasks are negotiated optional features. Missing integration is a support boundary; it is not automatically a protocol violation. Three transport layers use different installed SDKs (`@modelcontextprotocol/client/core` 2.1.0, sidecar `@ai-sdk/mcp` 2.0.67, and MCP SDK 1.x). Version split is an architectural observation, not by itself a defect.
