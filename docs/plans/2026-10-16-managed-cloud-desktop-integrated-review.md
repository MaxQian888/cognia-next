## End-to-end source trace

- Lifecycle → paid adapter: the same lifecycle seam and E2B adapter are retained. All three provider implementations forward admission checks; exact-build validation cannot create a post-check asynchronous gap. Persisted resource identity is retained if authority disappears after paid creation.
- Handoff: durable source provenance, delivery identity/revision, fixed commit and recovery bundle validation, read-only Git authority and the guest importer remain connected. Live preview and cross-Host transfer remain dormant.
- Results: encrypted Host evidence is authoritative; source conversation and run detail mount the owner-scoped view. Child history uses opaque references/counts, never image bytes. Agent verdict and independent human approval remain separate; parent completion and code merge are never inferred.
- Deletion: canonical session deletion prepares a device-local outbox and native evidence freeze before the local transaction commits. Retry commits native deletion, revokes source access, obtains fresh Host-derived task identifiers and invokes canonical task deletion. Desktop/headless startup installs backend-aware replay with the persisted device constraint. Archive retains evidence; committed deletion fences late publication/re-import. Physical cleanup can remain pending without claiming remote deletion succeeded.
- Privacy/dormancy: evidence is excluded from backup; no automatic share or model-send path was added. Contract constants, UI labels and protocol tests continue to deny production acceptance/delegation and automatic paid initiation before qualification. Read/history/cleanup paths remain reachable while creation is dormant.

Independent source reviews found no remaining blocker in the native receipt/process/lifecycle fixes or deletion wiring. These are static conclusions, not native runtime acceptance.
