# Agent sandbox and workspace gap analysis

Date: 2026-10-16. Baseline: `dev` at `c3a1307f6`, in a shared working tree.

Sources:

- Read-only code maps of the sandbox side (`crates/cognia-exec-sandbox`, `crates/cognia-sandbox-pool`, `crates/cognia-external-agent`, `lib/sandbox`, `packages/agent-*`) and the workspace side (`crates/cognia-task-workspace`, `crates/cognia-git`, `lib/task-workspace`, `lib/code-adoption`, the project editor).
- A citation-backed competitor survey dated 2026-10-16, covering Delta/DeltaDB, Cursor, Codex, Claude Code, Copilot, Jules, Devin, Factory, Amp, Warp, Conductor, Sculptor, Vibe Kanban, E2B, Daytona, Modal, Vercel, Cloudflare, Docker Sandboxes, Apple `container`, Firecracker and gVisor. It was checked against product documentation only, not by running the products.
- The externally supplied "Cognia × DeltaDB" audit. Every claim in it was re-checked against the code; corrections are in §4.

Every gap below was confirmed in source. Claims that could not be confirmed are listed in §5.

## 1. Where Cognia already matches or leads

None of these need new work:

- **OS command sandbox.** Seatbelt on macOS, bwrap with namespaces and seccomp on Linux, plus credential deny floors, env scrubbing and a fail-closed uninstalled backend (`crates/cognia-exec-sandbox`). On macOS the network allowlist is kernel-enforced (egress is pinned to the filtering proxy). That is stronger than Claude Code's default, which leaves reads open.
- **Isolated workspace per run.** Git worktree or shadow copy, a SQLite resource ledger, a content-addressed blob store, patch sets with hunk selection and per-turn undo, multi-root bundles, archive and restore, and lifecycle policy (15 active directories, 30-day snapshots, 1 GiB blob budget). This matches Codex desktop's managed worktrees (15 kept, snapshot before delete) and Cursor/Claude checkpoints.
- **Agent changesets and integration queue (ADR-0227).** Changesets are pinned to refs, with head-bound review and check records, a merge-tree prediction, and a compare-and-swap publish with rollback. That is beyond every surveyed product, including Delta, which only has "Pull Changes from verdict snapshot".
- **Remote sandboxes (ADR-0221).** E2B covers create, pause, resume, delete and allowlist egress. Kubernetes runs pods with a bundle init container. The Git proxy keeps credentials on the Host and refuses any push except to the task's own branch, which is stricter than Claude Cloud's proxy (the survey, §4).
- **Model credentials.** Agents get a gateway lease, never a provider key. Thirteen ambient credential variables are stripped. Setup reuse is keyed by fingerprint. Repository setup is declared in `.cognia/workspace.json`: `include` (the `.worktreeinclude` equivalent), sparse paths and cache links.
- **Canvas anchors.** Canvas comments use Yjs relative-position anchors (`lib/canvas/collaboration/relative-anchor.ts`).

## 4. Corrections to the external "Cognia × DeltaDB" audit

- **Right:** W1 (it calls this gap E), W2 (P0-B), W3 (P1-B), reusing `ResourceRefV1`, keeping Task Workspace as the authoritative source, and not adding a new CRDT engine or blob store.
- **Wrong place for the index.** It suggests materialising provenance next to the Dexie governance ledger. Task Workspace is the source of truth and runs headless and over companion RPC, so the index belongs in the Rust store (`crates/cognia-task-workspace/src/store.rs`). It must also survive task prune: today `prune` deletes expired tasks and their blobs, so any index keyed on task rows would vanish with them.
- **wsrev1 is the wrong precondition for the editor.** wsrev1 hashes the whole workspace. Any unrelated agent edit would refuse a save. The editor needs a per-file content hash.
- **"Agent context retrieval" (its P1-C) needs W2 first.** Without an index from a line to the turn that produced it, a history tool can only return file-level noise.
- **It misses the sandbox entirely.** Delta has no agent permission system or sandbox at all (delta.dev agentic-safety doc). On that axis Cognia leads, and S1–S5 are the actual parity gaps.
