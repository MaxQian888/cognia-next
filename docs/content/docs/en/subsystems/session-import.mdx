# Agent Session Import

<Status variant="stable">Stable · ADR-0062 · reuses sessions / messages</Status>

<TLDR>
  Eleven adapters read local histories or user-provided exports and project them into a version-1
  canonical session graph. Parent/child lineage, subagents, background tasks, lifecycle, tool state,
  checkpoints, rollback/rewind, compaction, multimodal parts, and explicit conversion loss survive when
  the source exposes them. The scan stays cheap; full graph parsing is paid only for selected sessions.
</TLDR>

## Two phases, because a full parse is expensive

A user scanning for importable history may be looking at thousands of JSONL files. Parsing all of them to
show a picker would be wasteful, so the adapter contract splits in two:

| Phase | Adapter method | Cost | Produces |
| --- | --- | --- | --- |
| **Scan** | `summarizeFile(content, locator)` | one read per file, no allocation of message objects | `SessionSummary`, or `null` when the file holds no session |
| **Import** | `parseGraph` | full parse | canonical sessions, relationships, source revision, and per-session loss |

`parseSession` remains the compatibility entry point for plugins. Cognia wraps it as a flat graph and
marks the fidelity downgrade rather than inventing unavailable relationships.

| --- | --- | --- | --- |

| Codex | 0.150.1 | parent/fork metadata, tools, plan/goal, rollback, compaction, collaboration messages | unknown rollout items are bounded/redacted diagnostics |
| OpenCode | 1.18.25 | arbitrary-depth child sessions, jobs, attachments, patch/snapshot, tool lifecycle | schema-private fields are not synthesized |
| Gemini CLI | 0.57.0 | `$set`, `$rewindTo`, JSON export, multimodal content, token/tool status, `agentId` | unavailable provider scratch state is reported as loss |
| Continue | 2.1.0 | mode/model/usage, structured content, tool-result correlation | upstream has no subagent transcript contract |
| Aider | 0.86.2 | configurable history path, conversational Markdown | Markdown is always lossy |
| Pi | 0.84.4 | branch vs subagent, direct bash, labels/session info, compaction | native resume still requires a live compatible preset |
| Cursor | 1.7 | local SQLite, Markdown exports, local subagent artifacts | no Cursor cloud/background-history authorization |
| Cline | 3.38 | `sessions.db`, manifest/messages/compaction artifacts, legacy task folders | local artifacts only |

| Qwen Code | 0.16-alpha | JSON/JSONL export, resume/branch/fork/rewind relationships | no dependency on undocumented private layouts |

The executable recovery mapping is generated by `buildExternalSessionSupportMatrix()` from the import
registry and external preset catalog. Kiro, Droid, and DeepSeek Harness remain runtime-only because no
stable public transcript format is available.

## Mirror and recovery semantics

- `source-mirror` follows source rewinds, deletions, relationship removal, and child tombstones while
  preserving Cognia-local decoration.
- Continuing with a Cognia model changes ownership to `cognia-owned`; source changes then become real
  divergence and never overwrite the local continuation.
- Native recovery is offered only when the import records a native session id and matching preset. The
  preset must already be configured and connected, `session/resume` must be live-verified, the original
  working directory must exist, and the resume handshake must succeed. Only then does ownership become
  `native-bound`; failed checks leave the mirror read-only.
- Native-bound event echoes deduplicate by the native session/revision identity.

`scan.ts` is the shared driver for every per-file JSONL source, so a new adapter only supplies the two
methods rather than its own walker.

## Where it lives

```
lib/session-import/
  scan.ts          # shared desktop-scan driver for per-file JSONL sources
  fs.ts            # walkFiles
  registry.ts      # source registration
  types.ts  codec-types.ts  graph.ts  support-matrix.ts  native-resume.ts
  to-parts.ts      # foreign message shape → Cognia message parts
  usage.ts         # token/usage reconstruction
  watch-import.ts  # follow a source as it grows
  adapters/
    claude-code.ts  codex.ts  opencode.ts  gemini-cli.ts
    aider.ts  continue-dev.ts  pi.ts
    cursor.ts  cline.ts  copilot-cli.ts  qwen-code.ts
    portable-agent-source.ts
  codecs/
    claude-code-codec.ts  codex-codec.ts  opencode-codec.ts

src-tauri/src/session_import.rs   # native filesystem access
hooks/session-import/  components/session-import/
lib/plugin/api/import-api.ts      # plugins can contribute sources
```

Desktop SQLite reads are read-only Rust transports with an allowlisted source id. File trees, SQLite,
fixed-argument runtime transports, and user exports remain separate trust boundaries; no shell string is
assembled from source content.
