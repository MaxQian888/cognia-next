# Companion API

<Status variant="beta">beta</Status>

<TLDR>
  Cognia exposes two contracts from the native Rust runtime. Paired devices use the public
  `/api/*` and `/ws/*` surface with short-lived DPoP credentials. The renderer-free Brain uses a
  loopback-only `/internal/*` service plane with a 24-hour service token. They share the Rust RPC
  dispatcher, but they are different trust boundaries and have separate generated OpenAPI files.
</TLDR>

## Two surfaces, one dispatcher

| Surface | Routes | Caller | Authentication | Specification |
| --- | --- | --- | --- | --- |
| Paired device | `/api/*`, `/ws/*` | Mobile and managed device clients | Device key, DPoP access token, socket ticket | `docs/api/mobile-companion-api.openapi.yaml` |
| Headless service | `/internal/*`, `/ide/content*` | Local renderer-free Brain and managed IDE | Loopback service token | `docs/api/headless-service-api.openapi.yaml` |

The public inventory is a subset of `KNOWN_COMMANDS`: the descriptor must target `execution` or
`host-admin` and declare HTTP transport support. Service commands cannot leak into the public spec.
The Headless inventory contains every dispatcher command because the Brain is the local execution
authority.

## Canonical public routes

| Purpose | Route |
| --- | --- |
| Health and readiness | `GET /healthz`, `GET /livez`, `GET /readyz` |
| Device bootstrap | `POST /api/auth/device/challenge`, `POST /api/auth/device/register` |
| Browser deployment config | `GET /api/auth/config` |
| Short-lived credential | `POST /api/auth/token` |
| WebSocket ticket | `POST /api/auth/socket-ticket` |
| RPC dispatch | `POST /api/_rpc/{name}` |
| Identity | `GET /api/whoami` |
| Event stream | `GET /ws/events?ticket=…&since=…` |
| Terminal and browser sockets | `/ws/terminal/*`, `/ws/browser/{session_id}` |

No `/api/v1/*`, `/ws/v1/*`, `cgnp2`, or bearer-device-JWT compatibility surface is mounted. Older
clients must complete a new `cgnp3` pairing and use the DPoP flow.

## Generated contract

The route catalog, command manifest, and Rust allowlist are the source inputs. Run:

```bash
pnpm companion-api:gen
pnpm companion-api:check
pnpm companion-api:lint
```

The artifact gate runs `companion-api:check`; Rust tests compare both concrete RPC path inventories
against the dispatcher. A route, descriptor, or allowlist change therefore cannot silently leave the
committed OpenAPI files stale.
