# Remote Control (Retired)

<Status variant="deprecated">Retired · 2026-08-09</Status>

The standalone Remote Control subsystem is no longer part of Cognia. Its axum
listener, `/api/v1` routes, renderer event receiver, Zustand store, audit UI,
and `?section=remote-control` settings entry were removed rather than kept as a
second host-control authority.

Use the canonical replacements:

- **Host and device control:** [Companion API](../companion-api), with its
  authenticated command manifest, device grants, and headless dispatch.
- **MCP ingress and governance:** [External Bridge](../external-bridge) and
  [ADR-0110](../../adr/0110-mcp-control-plane-governance).
- **Outbound event delivery:** `lib/webhooks/`, `stores/webhooks/`, and
  **Settings → Webhooks** (`?section=webhooks`).

ADR-0005 remains available as a marked historical record; its old file paths,
routes, and settings instructions are not current implementation guidance.
