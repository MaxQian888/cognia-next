# Protocol and security

Protocol 1.0 is JSON-RPC 2.0 over loopback TCP with `Content-Length` framing.
Frames, headers, queues, handles, in-flight requests, and deadlines are
bounded. The hello negotiates protocol major, Code API version, catalog hash,
host, canonical workspace, and capabilities.

The broker secret never enters code-server's environment, which every terminal,
task and language server inherits ([ADR-0212](../../adr/0212-the-broker-credential-is-a-file-not-an-environment)).
The host writes a single-use bootstrap credential to a `0600` file in a private
directory outside the user-data dir and puts only its path in
`COGNIA_CS_AGENT_CREDENTIAL_FILE`; the extension reads and unlinks it.
Challenge/HMAC authentication proves possession without sending the secret, and
both sides then derive a session key from the secret and the two handshake
nonces. Reconnects prove the session, which rotates on every hello. The content
endpoint's bearer is derived from the session and compared in constant time.
Whenever no extension host is connected the host re-mints the bootstrap file;
a bootstrap presented again while its first user is still connected closes
every connection for the workspace, re-mints, and warns the user.

Each connection has a monotonic generation. Disconnect fails all pending
requests. Responses, cancellation, progress, events, content handles, and
tickets from an old generation are rejected. Reconnect rebuilds registrations,
subscriptions, and snapshots only; actions are never replayed. The hello offers
every version the extension speaks and the host answers with the highest major
both share; minor differences ride on capabilities. A peer with no shared major,
or one that does not open with a `Content-Length` header (the retired `0.2.x`
newline bridge included), is answered with `IDE_BROKER_PROTOCOL_INCOMPATIBLE`
and closed, and the IDE status records why.

Large or binary values use one-shot 30-second content handles bound to root,
generation, plugin, provider, permission, and direction. Bytes move through a
separate authenticated loopback endpoint; credentials never appear in URLs.

Every callback revalidates the canonical host/root, workspace trust, current
generation, plugin enabled/version state, declaration, provider handler,
permission decision, and contextual ticket when required. Shell, debug, test,
notebook execution, external writes, and agent tools require contextual
confirmation. File paths and URIs are canonicalized on the IDE host; missing
descendants resolve through their deepest existing ancestor and symlink escape
fails closed.

Managed state lives in host-owned SQLite outside plugin-writable directories.
Global state, workspace state, and secrets are partitioned by user, host,
plugin, workspace, and area. State partitions have a 5 MiB quota. Secret values
stay in the OS keyring; SQLite stores only the partitioned key index.
`secrets:read` and `secrets:write` are rechecked on each operation. Proxy-local
state is a rebuildable cache, and secrets are never cached.

Webviews use `default-src 'none'`, typed messages, and content-addressed
resources. File, command, network, and secret operations return through broker
authorization. Protocol executables must be signed plugin resources, registered
host tools, or an executable explicitly selected by the user. Supervisors use
argument arrays, sanitized environments, canonical working directories,
resource limits, cancellation, and process-tree termination.
