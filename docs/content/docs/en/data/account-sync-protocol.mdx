# Account Sync Protocol v1

The byte-level specification of account sync moved to the services repository,
next to the sync Worker and the `@cognia/sync-protocol` package that implement
it: **[cognia-services: docs/protocols/account-sync-protocol.md](https://github.com/cognia-labs/cognia-services/blob/main/docs/protocols/account-sync-protocol.md)**.

[ADR-0215](../adr/0215-one-person-one-encrypted-sync-space-many-writable-hosts) records
_why_; the specification records _the bytes_. It covers, by section:

| §     | Topic                                                                    |
| ----- | ------------------------------------------------------------------------ |
| 0–3   | Invariants, primitives, identifiers, device and epoch keys              |
| 4–5   | The signed device registry and enrollment (six-digit approval, recovery) |
| 6–7   | Sessions, live updates, and the signed, padded op log                    |
| 8–9   | Snapshots and the client's per-field merge rules                         |
| 10–15 | Blobs, leases, counters, account lifecycle, quotas, self-hosting         |
| 16–17 | Error codes and the frozen test vectors                                  |

The app consumes the protocol as `@cognia/sync-protocol` at the cognia-services
commit pinned in `integrations/cognia-services.json`; a protocol change lands
there first. See [Account sync enrollment](../subsystems/account-sync-enrollment)
and [Account sync data](../subsystems/account-sync-data) for the app side.
