# Matrix 连接器配置指南

本指南将引导你为一个 Matrix 机器人账号准备访问令牌，并配置 cognia-next 以接入你的 Matrix homeserver。cognia-next 通过标准的客户端-服务端 `/sync` 长轮询接入 Matrix，无需公网地址。

---

## 1. 准备 homeserver 与机器人账号

1. 准备一个 Matrix homeserver —— 可以是公共服务（如 `matrix.org`），也可以是你自建的 Synapse 实例。
2. 在该 homeserver 上注册一个**专用于机器人的账号**（例如 `@bot:matrix.org`）。建议使用独立账号，而非你的个人账号。
3. 记下该账号的**用户名**与**密码**，稍后两种获取令牌的方式都会用到其中之一。

---

## 2. 获取访问令牌（Access Token）

cognia-next 使用一个长期有效的 `access_token` 调用 Matrix API。你有两种方式获取它。

### 方式 A：粘贴已有令牌

适合高级用户，或通过 homeserver 管理员 API 创建的机器人账号。

- 在 **Element** 客户端中：**设置 → 帮助与关于 → 高级 → 访问令牌**，复制其中的令牌。
- 或使用 homeserver 的**管理员 API**为机器人账号签发一个令牌。

令牌通常形如 `syt_…`。请妥善保管 —— 它等同于该账号的登录凭据。

### 方式 B：使用密码登录（仅桌面端）

配置对话框内置了**使用密码登录**功能，会调用 `POST /_matrix/client/v3/login` 自动换取令牌并填入令牌字段：

1. 在对话框中填写 **Homeserver 地址**。
2. 填写**用户名**（完整的 `@bot:matrix.org`，或仅用户名部分 `bot`）与**密码**。
3. 点击**登录**。成功后令牌会自动填入上方的访问令牌字段。

> 密码仅用于这一次换取令牌，**不会被保存**。该功能仅在桌面端（Tauri）可用；在浏览器中此按钮被禁用。

---

## 3. 在 cognia-next 中配置

1. 打开 cognia-next 并导航到 **设置 → 平台连接 → 适配器**。
2. 点击 **添加连接器** 并选择 **Matrix**。
3. 在 **Matrix 配置** 对话框中填写：
   - **显示名称** —— 用于在 cognia-next 中标识该机器人（例如 "My Matrix Bot"）。
   - **Homeserver 地址** —— 你的 homeserver 基础 URL（例如 `https://matrix.org`）。若不带协议前缀，会自动补上 `https://`。
   - **访问令牌** —— 粘贴第 2 步方式 A 复制的令牌，或使用方式 B 的**使用密码登录**自动填入。
4. 点击 **创建**。

访问令牌会**加密存放在系统钥匙串**中（账户名 `accessToken`），非机密的 homeserver 地址则保存在适配器设置里。

---

## 4. 让机器人加入房间

机器人只能收发它已加入房间内的消息：

1. 在你的 Matrix 客户端中打开目标房间。
2. **邀请机器人账号**（例如 `@bot:matrix.org`）进入该房间。
3. 确保机器人**接受邀请并加入**该房间（视 homeserver 配置，可能需要手动接受，或机器人已配置为自动加入）。

---

## 5. 验证连接

1. 在机器人所在的房间中 **@ 提及它**，或与它**私聊**发送一条消息。
2. 该消息应在一两秒内出现在 cognia-next 中。
3. 检查 **平台连接** 概览 —— 该适配器的状态应显示为 **运行中**。

如果适配器显示 **已停止** 或 **降级**：

- 确认**访问令牌**有效（令牌过期或被吊销会导致认证失败）。
- 确认 **Homeserver 地址**正确且可访问。
- 确认机器人确实已加入目标房间。
- 在 设置 → 平台连接 的 **Audit Log** 标签页中查看错误详情。

---

## 注意事项

- **传输方式**：Matrix 适配器是纯 TypeScript 的 `/sync` 长轮询实现，所有请求经由 Tauri HTTP 代理发出，**无需公网地址或 WebSocket**。冷启动时的首次 `/sync` 仅用于建立游标，历史消息会被丢弃，因此不会回放旧消息。遇到 5xx 或网络错误时会指数退避重试。
- **机器人身份识别**：适配器在启动时调用 `whoami` 解析机器人自身的 `user_id`（selfId），以便准确识别 @ 提及与对自身消息的回复关联。若 `whoami` 失败，适配器仍会启动，但自我提及检测会降级。
- **密码登录限制**：内置的**使用密码登录**仅在桌面端可用，且密码不会被保存，仅用于换取一次性令牌。
- **端到端加密（E2EE）房间不受支持**：`/sync` 传输直接读取房间时间线中的明文事件，**不包含任何解密逻辑**（无 olm / megolm 支持）。在端到端加密的房间中，机器人将无法读取消息内容。请仅在**未加密的房间**中使用该机器人。
- **富文本与互动**：消息以 `org.matrix.custom.html` 富文本发送，原生支持 Markdown、链接、引用、编辑、撤回、表情回应、回复与话题。A2UI 中的按钮 / 选择等交互元素以编号列表形式呈现，用户通过**回复**消息进行选择（回复关联），而非内联点击。
- **图片与文件**：当前阶段尚不支持向 homeserver 媒体库上传二进制内容，图片与文件会降级为消息正文中的链接或替代文本。
