# 企业微信（WeCom）智能机器人配置指南

本指南将引导你在企业微信管理后台创建一个**智能机器人**、获取长连接所需的凭据，并配置 cognia-next 通过长连接接入它。智能机器人长连接由桌面端的连接器运行时维护，无需公网 URL、加密回调或 IP 白名单。

---

## 1. 创建企业微信智能机器人

1. 登录 [企业微信管理后台](https://work.weixin.qq.com)。
2. 进入 **应用管理**，创建一个**智能机器人**。
3. 创建完成后，在机器人详情页记录两项凭据：
   - **BotID** —— 智能机器人的唯一标识，形如 `wb1234567890abcdef`。
   - **长连接 Secret** —— 长连接专用的密钥。

> **注意：** 长连接 Secret 与**回调模式**所用的 `Token` / `EncodingAESKey` **不是同一个**。智能机器人长连接不走回调模式 —— 它**无需公网 URL、无需消息加密、也无需配置 IP 白名单**。只要 BotID 与长连接 Secret 即可建立连接。

---

## 2. 配置 cognia-next

1. 打开 cognia-next 并导航到 **设置 → 平台连接 → 适配器**。
2. 点击 **添加连接器** 并选择 **企业微信（WeCom）机器人**。
3. 在配置对话框的 **「身份」** 分区填写：
   - **显示名称** —— 为该机器人取一个便于识别的名字。
   - **Bot ID** —— 第 1 步在管理后台记录的智能机器人 BotID（`wb...`）。
   - **Secret** —— 第 1 步记录的**长连接专用 Secret**。
   - **欢迎语**（可选）—— 用户首次打开机器人会话（`enter_chat` 事件）时发送的一段问候。留空则不发送任何欢迎语。
4. 点击 **创建**。

两项凭据（**Bot ID** 与 **Secret**）会加密存放在操作系统的钥匙串中，仅欢迎语等非敏感设置以明文保存在适配器配置里。适配器启用后，长连接会自动建立（`aibot_subscribe` 握手 + 30 秒心跳 `ping`，断线时自动指数退避重连）。

---

## 3. 配置快捷指令（可选）

企业微信智能机器人**没有持久菜单**这一原生能力。为此 cognia-next 在 `enter_chat` 时推送一张 `template_card` 菜单卡来模拟持久菜单：

1. 在配置对话框的 **「快捷指令」** 分区添加条目。
2. 每一条快捷指令映射成菜单卡上的一个按钮，按钮可绑定到一段**提示词**（`prompt`）或一条**斜杠命令**（`slash`）。
3. 当用户在会话中点击某个按钮，cognia-next 会把对应的提示词或斜杠命令作为一条用户消息送入运行时处理。

> 菜单卡最多展示 6 个按钮。当配置了快捷指令时，菜单卡会优先于纯文本欢迎语展示（让用户有可直接点按的入口）；未配置时则回退为第 2 步的纯文本欢迎语。

---

## 4. 验证连接

1. 在企业微信中打开你的机器人会话，并发送一条消息。
2. 该消息应在一两秒内出现在 cognia-next 中。
3. 检查 **平台连接** 概览 —— 该适配器的状态应显示为 **运行中**。

如果适配器显示 **已停止** 或 **降级**：

- 验证 **Bot ID** 是否正确（`wb...`）。
- 验证 **Secret** 是否为**长连接专用 Secret**（而非回调模式的 `Token` / `EncodingAESKey`）。
- 在 设置 → 平台连接 的 **Audit Log** 标签页中查看 `aibot_subscribe` 握手的错误码与详情。

---

## 注意事项

- **主动推送限制**：企业微信仅在用户**至少给机器人发过一次消息之后**，才会向该会话投递主动推送。也就是说，**定时任务 / 工作流**触发的主动消息（通过 `aibot_send_msg` 发送）只能送达此前已与机器人有过互动的会话；向从未给机器人发过消息的用户主动推送会被平台丢弃。
- **流式回复**：在回复触发消息时，cognia-next 会以**流式**方式逐步刷新同一条消息（内部通过 `streamReply` / `onPartial` 复用同一个 stream id，最终以 `finish` 标记定稿）。流式回复必须复用触发回调的 `req_id`，而该回复窗口约有 10 分钟有效期；超过窗口后改为通过 `aibot_send_msg` 主动推送。
- **长连接运行位置**：长连接的 socket 生命周期由桌面端 Tauri 的连接器运行时（Rust WS 桥）持有，可在网页视图（webview）重载时存活。因此该适配器通常运行在桌面端的连接器运行时中。
- **不支持的能力**：智能机器人长连接协议没有通用的消息编辑（`edit`）、撤回（`delete`）、正在输入指示器（`typing`）或历史拉取（`history.fetch`）帧；其中 `aibot_respond_update_msg` 仅用于更新处于交互态的 `template_card`，并非通用编辑。
- **A2UI 与卡片**：助手的交互式 A2UI 界面会尽量投射为 `template_card` 的按钮（`button_interaction`，企业微信唯一会回传点击回调的交互组件），其余无原生对应的组件会降级为纯文本镜像并附加到 markdown 正文中。markdown 正文上限为 20 480 字节。
