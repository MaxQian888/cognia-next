# Cognia 官方账号

<Status variant="beta">第 1 阶段 · 仅身份 · ADR-0215</Status>

<TLDR>
  每个构建都内置一个无需配置的部署：位于 `https://id.cognia.cn/api/auth` 的 Cognia 官方账号。
  没有自托管部署时，发现逻辑会提供它，云端闸门对每个配置文件**只展示一次**登录页；登录后，配置文件绑定到一个人，
  其 id 就是签发方自己的 `usr_` subject。自托管的 Logto 部署仍会取代它，自托管 Web 镜像则会关闭它。
  同步属于第 3 阶段，本页只讲身份。
</TLDR>

## 登录

1. 发现逻辑在原先返回 `none` 的地方返回 `official`：没有宿主、单用户宿主、桌面服务已停止，或手机只能经中继访问宿主。
   headless 宿主永远不会；“设置”探测单个网关时传入 `officialFallback: false`。
2. 在配置文件作出选择之前，闸门会一直提供官方登录页。“登录”和“继续离线”都按配置文件永久记在 `localStorage` 中。
   此后登录页不会自行出现；“设置 → 账号”通过请求总线要求展示，闸门会把应用替换为登录页直到完成。
3. 登录页在授权请求上带 `provider=<id>`，签发方页面直接跳到该提供方。桌面和手机使用 `cognia-app` 与
   `cn.cognia.app:/auth/callback`；浏览器使用 `cognia-web` 与本站的 `/logto/callback`；CLI 使用回环地址。
4. `completeSignIn` 绑定配置文件并通知桌面宿主。ID 令牌中的 `cognia_identities`（飞书为
   `{provider: "lark", tenant, subject: union_id}`）关联到此人，union id 匹配的飞书主体会记下这次登录的 subject。

没有组织，也没有协作服务器：已激活的会话直接通过闸门。

## 此人的 id

subject 不透明，因此 id 由哈希派生（`usr_` + SHA-256(`user\n<issuer>\n<subject>`) 的前 24 个十六进制字符）。
只有**官方**签发方例外：它本身签发 `usr_` id，因此其合法用户 id 形式的 subject **就是** id。其他所有签发方（包括自托管 OIDC 签发方）
一律哈希派生：渲染层可以指定的网关绝不能签发一个等于他人官方 id 的 subject。
渲染层（`expectedUserId`）与宿主（`expected_user_id`）都读取
`crates/cognia-companion-security/fixtures/identity-id-vectors.json`。

## 桌面宿主信任什么

`account_bind_person` 在记录此人之前验证访问令牌。headless 宿主只信任其环境变量中的签发方；桌面信任用户选定的部署，
**再加上**编译进构建的官方签发方；若选定的部署就是官方签发方，则按官方锚处理。令牌中未经验证的 `iss` 只用于选择；
release 构建绝不从运行环境读取官方签发方。

| 覆盖项 | 位置 | 作用 |
| --- | --- | --- |
| `NEXT_PUBLIC_COGNIA_ID_ISSUER`、`NEXT_PUBLIC_COGNIA_ID_AUDIENCE` | 应用构建 | 让渲染层指向 staging 或本地 Worker |
| `NEXT_PUBLIC_COGNIA_OFFICIAL_ACCOUNT=0` | 应用构建 | 关闭官方账号（自托管 Web 镜像） |
| `COGNIA_OFFICIAL_ISSUER`、`COGNIA_OFFICIAL_AUDIENCE` | 桌面构建；仅 debug 构建可在运行时设置 | 宿主的信任锚 |
| `COGNIA_ID_ISSUER`、`COGNIA_ID_AUDIENCE` | CLI 环境 | CLI 的签发方 |

## 注销账号

“设置 → 账号 → 注销账号”会说明删除什么（账号及其关联登录方式）、保留什么（设备上的一切），提供备份入口，
并要求重新登录一次（`prompt=login&max_age=0`）。只有新登录的是同一个人时才发出请求，并以其 ID 令牌作为证明；
配置文件保留原有会话。待注销状态会显示清除日期，在此之前可以撤销。7 天后，Worker 的每小时任务先删除此人的同步空间（通过同步 Worker 的 `SyncAdmin`，见[账号同步设备登记](./account-sync-enrollment)），再删除令牌、授权、会话、关联账号和用户。

## 已知限制

- 在飞书应用市场版应用就绪前，只有自建应用所在租户能用飞书登录。
- 浏览器把令牌放在 IndexedDB 回退存储里，其密钥在 `localStorage` 中；手机使用 Keychain / Keystore。
- 签发方会关联 Google 和 Apple 身份，但本地身份词汇表会跳过它们。
