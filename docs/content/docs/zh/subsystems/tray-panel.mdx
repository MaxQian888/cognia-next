# 托盘面板

<Status variant="beta">Beta · 桌面端与移动端 · ADR-0225 第一至四阶段</Status>

<TLDR>
  左键点击托盘图标，会打开一个置顶的小窗口：页头放工作区范围切换和总体状态胶囊，中间是一列**速览模块**，
  底部固定一条**委托栏**，最下面是页脚。面板不持有数据，自己也不执行任何操作。面板持有租约期间，
  主窗口构建一份不含内容的 `GlanceSnapshotV1` 推给它，并替它执行请求。每个模块只汇总一个子系统并路由过去，
  控制权留在子系统自己手里：Agent Fleet 的审批与逐任务停止仍在 Island 上。在手机上，同一套模块组成首页与速览抽屉；
  已配对的手机经伴侣连接获取桌面构建的切片。
</TLDR>

## 布局

| 区域     | 内容                                                                                   |
| -------- | -------------------------------------------------------------------------------------- |
| 页头     | 标题、范围切换（全部 / 当前工作区）、状态胶囊（自动化 › 待处理 › 运行中 › 空闲）、刷新、设置、关闭 |
| 速览栈   | 已存布局中可见的模块，按顺序排列。面板达到最大高度后滚动                                   |
| 委托栏   | 主托盘操作，呈现为一行可增高的输入框，其余字段放在选项菜单里                               |
| 页脚     | 编辑、预设切换、打开 Cognia，以及快照的新鲜度（「12 秒前更新」/「连接中…」）              |
| 调整手柄 | 拖动，或按 ↑ / ↓ 以 40 px 步进，设置最大高度（240–860 px）                                |

窗口随内容自适应：`ResizeObserver` 让原生窗口贴合卡片尺寸，左上角位置保持不动。各区块在同一个容器里用细线分隔，
不做成一张张卡片。

## 模块

每个模块都登记在 `lib/glance/registry.ts`，声明可用尺寸、对应的快照切片和路由去向。模块不支持的尺寸会降级到最接近的可用尺寸。

| 模块       | 尺寸                          | 显示                                                                 | 路由到                           |
| ---------- | ----------------------------- | -------------------------------------------------------------------- | -------------------------------- |
| `fleet`    | compact · standard · expanded | 运行 / 待处理 / 失败计数、前几行，以及正在运行的可视化工作流。**只读** | Island，并聚焦到被点击的行；工作流一行打开其运行记录 |
| `usage`    | compact · standard · expanded | 今日 / 7 天 / 30 天的 token、轮次或花费、预算进度、各提供商占比        | 设置 › 订阅 › 用量                |
| `quota`    | compact · standard · expanded | 每个已登录来源的窗口「已用 %」，状态为正常 / 预警 / 耗尽 / 出错 / 过期 | 设置 › 订阅                       |
| `agenda`   | compact · standard            | 下一次计划运行、上次结果、未读通知、连接状态                          | 计划任务条目、通知中心、设备      |
| `activity` | compact · standard · expanded | 1 / 3 / 12 个月的每日热力图、连续天数、高峰时段                        | 设置 › 订阅 › 用量                |
| `quick`    | compact · standard            | 桌面：主操作之外的托盘操作；手机：布局自己的快捷入口网格             | 设置 › 桌面 / 手机的布局编辑器    |
| `recents`  | compact · standard            | 最近几次会话                                                          | 对应会话                          |
| `pet`      | compact · standard            | 宠物状态，以及喂食 / 玩耍 / 抚摸 / 睡觉 / 清洁                         | 宠物页                            |
| `plugin:<插件>:<id>` | 由插件声明                 | 插件发布的统计、行与动作（见[插件模块](#插件模块)）                    | 插件自己的命令                    |

预设（`balanced`、`usage-first`、`agent-ops`、`minimal`）位于 `lib/glance/presets.ts`。
已存布局只能通过 `normalizeGlancePanelSettings` 读取：未知 id 丢弃，重复项保留第一个，缺失的模块以隐藏状态补在末尾，越界高度会被钳制。
默认宽度为 460 px（`wide`）。未保存或无效的宽度使用此默认值；有效的已存选择，包括 320 px（`narrow`）和 380 px（`standard`），均会保留。

## 插件模块

插件通过 `glance.module` 扩展点以**数据**形式贡献模块：声明模块（`manifest.glanceModules[]` 或 `ctx.glance.register`），
再用 `ctx.glance.update` 发布统计、行与动作。宿主用与自带模块相同的组件渲染（`components/glance/modules/glance-plugin-module.tsx`）：
compact 为一行（摘要或第一项统计），standard 为统计条、前三行与动作，expanded 显示全部行。插件永远不会把 React 注入速览界面。
编写方式见[速览模块](../plugin-dev/glance-modules)。

- **注册表。** `lib/glance/plugin-registry.ts`（每个运行插件的渲染进程一份）保存声明与数据，进入时清洗并限量（`lib/glance/plugin-data.ts`）：
  每个插件最多 8 个模块，每个模块最多 4 项统计、8 行、3 个动作，文字都是短标签。
- **快照。** `GlanceSnapshotV1.plugins` 携带当前平台的模块目录（标题在主窗口里解析，插件的语言包在那里），以及可见插件条目的数据。
  编辑器的添加列表会提供目录中的每个模块。
- **是否在屏幕上。** 每次构建都会报告它显示了哪些插件条目；`ctx.glance.onVisibilityChange` 通知插件，没人显示时插件可以停止计算。
  Python 插件无法把回调交给宿主，它通过 `onGlanceVisibilityChange` 钩子得到同样的信息：由
  `lib/plugin/messaging/glance-visibility-hook-source.ts` 依据注册表对账（插件开始监听时先给一次当前状态，之后每次翻转都通知，且只发给模块所属的插件），再用 `ctx.glance.update` 发布数据。
- **动作。** 点击只发送 `plugin-action`（条目与动作 id），从不发送命令。主窗口在插件发布的数据里查到对应命令，
  只运行该插件自己的 `<pluginId>.<command>`（`lib/glance/plugin-actions.ts`）：清单命令、插件用 `ctx.commands` 注册的斜杠命令，或命令总线上的命令。
- **插件关闭时。** 插件被禁用或卸载后，布局仍保留它的条目；速览列表跳过它们，编辑器把显示中的条目标为「插件已关闭」，可以移除。
  应用预设会移除插件条目，添加列表仍会继续提供这些模块。

## 编辑

页脚的**编辑**会就地把速览栈换成布局编辑器：按住模块的拖动手柄（或按空格后用 ↑ / ↓）调整顺序，选择尺寸、隐藏模块，或把隐藏的模块加回来。
列表下方还有两个面板专属开关：委托栏与宽度档位。按 Esc 或**完成**退出编辑模式，面板保持打开。每次修改都会立即显示，
并作为请求发出（`set-layout`、`set-delegate-visible`、`set-width`）；请求失败时面板回到已存布局并说明原因。

任何修改都会让布局变成**自定义**。编辑旁的预设切换会把模块及其顺序和尺寸重置为某个内置预设（`apply-preset`），
宽度、高度、范围与模块选项保持不变。隐藏委托栏后，主操作会移到快捷操作中，依然一键可达。

编辑器是 `components/glance/glance-layout-editor.tsx`，它能做的每种修改都是 `lib/glance/layout-edit.ts` 中的纯函数，与设置页编辑器共用。

## 数据流

```
tray-panel 窗口                           主窗口
───────────────                           ──────
useGlanceConsumer ── glance://subscribe ──▶ GlanceSubscriptionRegistry（租约，TTL 60s）
   （可见时每 20s 续约）                          │
                                                  ▼
                                          useGlanceSources(active)
                                          只构建可见模块的切片
                    ◀── glance://snapshot ── GlancePublisherInitializer（120 ms 防抖）
send(request) ───── glance://request ────▶ executeGlanceRequest
                    ◀── glance://result ───
```

- **租约。** 面板隐藏时结束租约；过期租约每 10 秒清理一次。没有存活的租约时，发布端不做任何计算。
- **顺序。** 快照带 `epoch`（每次发布端启动生成）和 `revision`，消费端只接受更新的快照。
- **不含内容。** 切片只携带计数、标签和 id，从不携带提示词、提问或权限请求的内容。名称在离开主窗口前会先脱敏并截断。
- **操作目录。** 快捷操作与委托栏同样来自快照（`actions`），由 `AppSettings.trayPanelActions` 解析而来。第一份快照到达前，
  快捷操作显示加载中，委托栏不出现。`open` 触发的操作每次显示面板只运行一次，时机是显示之后到达的第一份快照，因此总是使用最新目录。
- **请求。** `parseGlanceRequest` 严格校验每个请求。路由类请求在主窗口接手后关闭面板；轻量请求（范围、用量口径、花费显示、
  活跃度区间、尺寸、额度刷新 / 启用、宠物照料）不关闭面板。15 秒内没有回应的请求按超时处理，转圈不会一直挂着。

## 归属规则

- 面板从不自己执行托盘操作。原生操作交给 Rust，其余操作照旧经 `tray-panel://run` 交给主窗口。
- Fleet 只是摘要。点击某一行会调用 `requestIslandFocus`：打开 Island（窗口挂载前先暂存这次聚焦），并固定该行，让它的审批与回答直接可见。
- 「查看通知」会打开状态栏的通知中心（`requestNotificationCenter`）；没有挂载通知铃铛时，退回到 设置 › 通知。
- 额度读数来自主窗口的 `providerLimits` 表。在磁盘上发现的登录会路由到 设置 › 订阅 去采纳；已停用的保险库账号可以在面板里直接启用。
- 遵守 ADR-0165 的显式开启约定：花费默认隐藏，需用户主动显示；切换到「全部工具」用量口径前会先征得同意。额度等账号级数据从不按工作区过滤。

## 设置

设置 › 桌面 › 托盘面板 提供完整编辑器：

- **模块**：与编辑模式相同的布局编辑器、预设切换、委托栏开关，旁边是实时预览。预览用本窗口自己的数据渲染真实模块，
  宽度与最大高度和设置一致。它以被动方式构建（不刷新额度、不探测登录），并且是 `inert` 的，只是一幅画面，不是第二个面板。
  **手机布局**：配对的手机保存过自己的布局后，可把它的模块、顺序与尺寸复制过来。
- **面板布局**：宽度档位（320 / 380 / 460 px）、最大高度、默认范围，以及打开时委托栏是否自动获得焦点。
- **操作**：操作目录编辑器。

布局存为 `AppSettings.trayPanelLayout`，目录存为 `AppSettings.trayPanelActions`，同步类别都是 `desktop-only`，
因此无需 Dexie 迁移即可随备份与账号同步保存；面板打开时，下一份快照就会按新设置重绘。

### 迁移

ADR-0225 之前，目录保存在 Tauri store 的 `trayPanel.actions.v1` 下，因为面板窗口直接读取它。`TrayPanelInitializer`
在设置加载完成后（加载失败时不会）把它一次性导入设置，并且只在保存成功后才删除该 pref，因此中断的导入会再次执行。
如果设置里已经有目录（从另一台桌面同步而来），以设置为准并丢弃 pref。`resolveTrayPanelActions`（`lib/tray-panel/catalogue.ts`）
会修复读到的内容：丢弃格式错误或重复的条目，改写已退役的原生效果，并补回新版本新增的内置操作。

## 移动端

手机以触控尺寸渲染同一套模块组件（`components/glance/`），来源是同一份布局 `AppSettings.mobileGlanceLayout`（`GlanceMobileSettings`）：

- **速览抽屉。** 从顶栏的速览按钮打开的底部抽屉（`components/mobile/glance/mobile-glance-drawer.tsx`），在一个容器里显示所有可见模块。
  页头：数据来自哪里、桌面的连接状态、工作区范围、刷新。页脚：编辑、预设切换，以及读数的新鲜度。编辑会就地把模块栈换成布局编辑器。
  有事项待处理（读自手机已持有的 Fleet 镜像）或失败时，按钮带一个圆点；宽度低于 384 px 时它折叠进 ⋮ 菜单，圆点随之保留。
- **首页。** 标记了 `home` 的可见模块按布局顺序显示在输入框下方（`mobile-glance-home.tsx`）。Fleet 只在有任务运行、待处理或失败时出现，
  快捷入口为空时不显示任何内容，因此首页和以前一样安静。
- **快捷模块。** 在手机上它是布局自己的快捷入口网格（`shortcuts`），而不是桌面的托盘操作。
- **一个编辑器**（`mobile-glance-editor.tsx`），出现在抽屉的编辑模式和 ⋮ 菜单的「首页与速览」面板中：模块、尺寸、首页固定（房子开关）、预设、快捷入口。

只构建屏幕上需要的内容：显示首页时只构建已固定的模块，抽屉打开时构建所有可见模块，进入后台时什么都不构建。

### 已配对的手机

独立运行的手机用本机数据构建所有切片。已配对的手机自己构建最近会话（会话会同步），其余切片来自桌面：Fleet（Island 只存在于桌面内存）、
用量与活跃度（`sessionUsage` 不同步）、额度（`providerLimits` 与已解锁的保险库）、日程，以及宠物（宠物是否开启是桌面专属设置）。

```
手机                                        桌面主窗口
────                                        ──────────
glancePhoneStore ── glance_subscribe ─────▶ glanceRemoteHub（按设备 + 消费者的租约，TTL 60s）
  （屏幕上需要时每 20s 续约）                       │  合并后的需求
                                                   ▼
                                           useGlanceSources（按需求生成的配置）
                    ◀── glance://update ── GlancePublisherInitializer（120 ms 防抖）
刷新 / 重试 ──────── glance_request ──────▶ 同一套额度与用量数据源
启用来源 ─────────── glance_quota_enable ─▶ （一次桌面设置写入）
```

- **发送需求，而非布局。** 手机发送屏幕上需要的桌面来源模块，以及它们依赖的选项（范围、用量口径、花费、活跃度区间）。顺序、尺寸与首页固定从不离开手机。
  多台手机时，模块取并集，选项以最近一次变更为准；每个切片都标明自己按什么选项构建。
- **永远不会收到的内容。** 手机的快照不含托盘操作目录（`actions` 为空），也不含目标标题；它会带上托盘布局的条目（`hostLayout`），供手机复制。
- **来源标签。** 每个由桌面构建的模块都显示桌面名称与读数的时间；租约断开后标注桌面离线并保留最后一次读数。
  桌面无法提供的模块会就地说明原因：桌面离线且尚未收到数据，或桌面不提供速览（headless 大脑回答 `headless_host`，旧版桌面不声明 `glance.remote`）。
- **不进离线队列。** 三个命令都不在离线外发队列中：稍后重放的刷新回答的是已经过去的时刻。

- **插件模块。** 已配对的手机只显示桌面端的插件模块，从不显示自己的：需求里会列出这些条目；手机的布局编辑器打开时，
  即使屏幕上没有桌面来源的模块，也会请求桌面的插件目录（`catalog`）。它们在手机上只读：动作按钮显示为禁用，并注明「在桌面上操作」。
  未配对的手机运行自己的插件。

### 迁移与复制

ADR-0225 之前，首页有自己的模型 `mobileHomeLayout`（快捷网格加三个板块开关），仪表盘也有自己的开关（`welcomeStats.enabled`）。
在手机保存 `mobileGlanceLayout` 之前，`normalizeGlanceMobileSettings` 每次读取时都把旧状态读入新模型：运行中卡片变成 Fleet 的首页固定，
网格变成快捷模块的固定，仪表盘变成用量与活跃度的固定，最近会话仍是最近会话。不预先写入任何内容，第一次编辑时才保存新字段。

该布局在设置同步中属于 `shared`，每个账号一份。手机的编辑器可以复制桌面的顺序、尺寸与可见性（手机自己的首页固定保持不变）；
设置 › 桌面 › 托盘面板 可以复制手机的布局（首页固定与快捷入口仍只属于手机）。

## 菜单栏标题

在 设置 › 桌面 › 托盘 中，把菜单栏读数设为「标题文字」后，会出现**标题字段**：最多六个字段的有序列表，在托盘图标旁显示为一行，
例如 `1D 103.3M · 7D 12.6B · ▶2 · ⚑1 · Q 82%`。

| 字段     | 显示                                                         |
| -------- | ------------------------------------------------------------ |
| 用量     | 今天、7 天或 30 天的 token 或花费，按托盘的统计口径          |
| 运行中   | 正在运行的 Fleet 任务数                                      |
| 等待审批 | 等待审批的 Fleet 任务数                                      |
| 额度     | 各额度窗口中最高的已用比例（或已固定订阅的）                 |
| 预算     | 最紧的花费预算的已用比例                                     |

没有内容可报的字段（没有任务、没有读数、窗口内没有轮次）会被省略；含未定价轮次的花费显示为「≥$x」。
标题默认关闭（ADR-0165），只在开启时、且只为所显示的字段运行数据源（`lib/tray/title.ts`，纯模型与格式化在 `lib/tray/title-format.ts`）。
字段出现之前保存的标题会迁移为其原指标对应的那一个数字。Windows 没有菜单栏标题：该选项在 Windows 上禁用，卡片提示改用图标角标。

## Capacity Dock

Capacity Dock 的**套餐额度**模式按每个正在查询的额度来源各画一行，取其最紧窗口的已用比例，最紧的排在最前；
数据来自与面板额度模块相同的额度切片构建器，因此两者对每种状态的判断一致：过期或出错的读数保留最后的比例但不再着色，并在详情里说明。
主窗口通过 Dock 自己的推送（`usage-dock://state`，在花费投影旁附带 `quota`）提供数据，Dock 显示期间按共享的五分钟节流刷新；预算模式完全不读取额度。

## 交付

第一阶段交付了注册表、快照、桌面面板、Fleet 路由和额度状态；第二阶段交付了就地编辑、预设、带实时预览的设置编辑器与目录迁移；
第三阶段交付了手机首页与速览抽屉、配对手机通道与来源标签；第四阶段交付了插件模块扩展点、可组合的菜单栏标题与 Capacity Dock 额度数据源。
