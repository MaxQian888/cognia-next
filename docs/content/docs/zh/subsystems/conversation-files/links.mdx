# 对话文件链接

文件链接就是在对话链接上多加三个查询参数，因此只认识对话的解析器也仍然能打开对话。

| 外壳 | 形式 |
| --- | --- |
| 桌面端 | `cognia://session/<id>?view=files[&path=<FileSpacePath>][&line=<n>]` |
| 应用 / 网页 | `/?session=<id>&view=files[&path=…][&line=…]` |
| CLI | `cognia open --session <id> --files [--path <FileSpacePath> [--line <n>]]` |

规则：

- `view` 不是 `files` 时忽略该参数：只打开对话。
- `path` 必须是 FileSpace 路径——绝对路径、POSIX 形式、不含 `.` 或 `..` 段，不含反斜杠或控制字符。格式错误的路径只丢弃路径，
  不丢弃视图，因此链接仍会落在“对话文件”面板上。CLI 则直接拒绝格式错误的路径，而不是打印一个会被应用降级处理的链接。
- `line` 是 1 到 10,000,000 之间的整数，只有和路径一起出现时才生效。
- 移动端打开对话并忽略文件字段：手机上没有工作区文件系统。

## 复制链接

停靠栏编辑器文件树中的“复制对话链接”、文件工具卡片上的链接按钮，以及“对话文件”面板中的每一行，生成的是同一种链接。
工具卡片里的路径可以是绝对路径，也可以是相对于工作目录的路径；它会经由对话的 FileSpace 重新寻址。不属于任何挂载点的路径
没有链接（操作会直接说明，而不是生成一个无法打开的链接）。

## 契约测试

`lib/filespace/link-fixtures.json` 以精确字符串列出链接。`lib/filespace/links.test.ts` 逐条构建并解析；
`crates/cognia-cli/src/commands/open.rs` 用 CLI 参数构建出同样的字符串。两边都使用表单编码（`/` → `%2F`、空格 → `+`、
`~` → `%7E`），因此字符串必须完全一致。
