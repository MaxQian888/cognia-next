# Run、同步与运维

## 一个共享会话最多只有一个正在执行的 Agent Run

发起客户端携带稳定 device id、Run id、operation id 和随机生成且重试时保持不变的 token 申请租约。服务端验证 `session.run`，只保存 token digest，返回 token 及绑定用户、设备、会话和 Run 的短期租约。使用相同 operation id 更换凭据或 Run 会被拒绝。心跳和释放都必须携带匹配会话的 device id 与 token；已过期的心跳不能恢复执行。本地模型/工具 runtime 用它发布 Run 事件。并发启动收到 `409`，输入进入队列而不会执行。

只有发起人、maintainer 或 owner 可以 steer。心跳丢失会先暂停 Run，宽限期后转为失败。其他设备绝不静默接管，因为重复执行不可逆工具比要求用户显式重启更危险。

普通工具由发起人审批。高风险、不可逆或扩大权限的工具必须由 maintainer、owner 或非 Guest approver 审批。审批解决会比较当前 revision 并原子消费一次状态转换，因此双击不会批准两次。

普通人工消息的作者由已认证成员身份确定，角色只能为 `user`。仅创建者 owner 在会话明确处于私有历史导入阶段、尚未激活时，才可以保留历史作者以及 assistant/system 角色。

## HTTP 负责修复，WebSocket 负责加速

命令以及所有已存储事件的读取都走 HTTP。WebSocket 用单次 stream ticket 打开，只负责通知成员"有变化"：它每宣告一条已存储事件，客户端就从自己的游标拉取一次，reducer 只应用 `lastSequence + 1`。缺口、重连或策略变化同样触发拉取。每次策略事件之后，发送更多事件前都会重新检查成员身份。

## 成员实时观看 Run

Run 的回复不只是边生成边存储（ADR-0241）。若服务端在 `/health` 中报告 `shared-chat-live-v1`，执行端还会用 run token 向 `…/runs/{run}/live` 发送实时帧（复用 transcript 编解码器的补丁与 2 秒关键帧，约每秒四帧）。服务端对每一帧都检查租约、持有者身份和共享聊天灰度开关，只转发给协商了 `cognia.chat.v2` 的成员 socket，不做任何存储；`cognia.chat.v1` socket 永远收不到实时帧。实时帧按设计只会落后于事实、不会超前：已存储的 correction 仍是唯一记录，在回复结束时写入，实时帧承载回复期间最多每 10 秒写一次（服务端不支持实时时仍是每秒一次）。

成员看到的内容对两个通道是同一份投影：

- **文本**按整条消息脱敏。回复生成期间，最后 256 个字符留在执行端；私钥、JWT 或 URL 凭据从起始标记开始保留，直到被脱敏。
- **工具**按会话的工具详情级别展示。`summary`（默认）显示工具名、涉及的工作区路径和 diff 统计；`full` 只能由 owner 或 maintainer 开启，还会显示脱敏后的命令、编辑、搜索和待办。每次发布都带上投影时的级别 revision，服务端拒绝过期的 revision（`409 tool_detail_stale`），执行端随即重新投影。MCP 与插件工具从不共享输入。
- 未通过 PII 检查的部分替换为一个惰性的"已隐藏"行，其余部分照常发布。

成员在 6 秒收不到帧时丢弃正在生成的回复；该消息被撤回或 socket 关闭时立即丢弃；已结束的回复保留到拉取读过最终 correction 为止（最多 10 秒）。撤回还会让服务端不再转发该消息排队中的帧。

移除成员会关闭该用户的流、撤销附件 ticket、取消其排队输入，并结束其活动租约。客户端清除对应共享投影。离线模式只保留缓存读取与草稿，不存在延迟消息或 Run outbox。

## Break-glass 不等于 Org admin 自动读取

Org admin 不会通过普通成员 API 发现私有会话内容。事故处理中，拥有 workspace-manage 能力的 Org admin 必须填写理由，并选择一到六十分钟的有效期。Grant 绑定该管理员与会话。每次读取原始事件都会检查有效期，并写入不含内容的 `session.breakGlassRead` 审计，其中 `rawContentAccessed=true`。

## 运维与回滚

1. 在两个开关关闭时应用追加式 migrations。
2. 对选定组织启用服务端开关，验证协议 v2 health。
3. 向同一 canary 人群发布启用客户端开关的构建。租约凭据变更须配套发布客户端：申请时发送稳定 token，释放时在请求体发送 `{ deviceId, token }`。旧客户端无法通过加固后的接口释放租约；断连后租约仍会正常过期。
4. 一旦出现跨租户放行、移除后仍可访问、无法恢复的事件缺口或重复工具执行，立即停止灰度。
5. 关闭任一开关完成回滚；不要 down-migrate，也不要删除共享数据。

协作服务绝不能记录正文、token、邮箱、prompt、工具输入或附件 URL。运维维度只允许动作、事件、风险、阶段与原因分类。服务中断或回滚期间，私有本地聊天继续可用。
