# 快速开始

从全新 clone 到能跑的 Web 开发服务器**和**一个能弹出窗口的 Tauri 桌面应用。首次构建约 15 分钟，之后只需几秒。

## 前置要求

| 工具             | 版本       | 用途                                                                |
| ---------------- | ---------- | ------------------------------------------------------------------- |
| **Node.js**      | ≥ 20.x     | Next.js 16 / React 19 运行时                                        |
| **pnpm**         | 10.x       | 整个 monorepo 单一 lockfile                                         |
| **Rust**         | ≥ 1.84.1   | Tauri 2.11 + 传递依赖（`ocr-paddle` 抬高 MSRV）                     |
| **C/C++ 工具链** | 因平台而异 | 编译原生依赖（sqlite-vec、webrtc-rs、wasmtime 等）                  |

平台特定说明：

<Tabs groupId="os" persist items={["Windows", "macOS", "Linux"]}>
  <Tab value="Windows">
    安装 **Visual Studio Build Tools**（含 "C++ 桌面开发" 工作负载）。**WebView2 Runtime** 在 Windows 11 上已自带；Windows 10 请从 [Microsoft Edge WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) 安装。
  </Tab>
  <Tab value="macOS">
    安装 Xcode 命令行工具：

    ```bash
    xcode-select --install
    ```

    Apple Silicon 与 Intel 都无需额外设置。

  </Tab>
  <Tab value="Linux">
    按发行版安装 GTK / WebKitGTK / libsoup，参见 [Tauri 前置要求](https://tauri.app/start/prerequisites/)。

    Ubuntu / Debian：

    ```bash
    sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
        libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
    ```

  </Tab>
</Tabs>

验证：

```bash
node --version    # v20.x 或更新
pnpm --version    # 10.x
rustc --version   # 1.84.1 或更新
cargo --version
```

## Clone 与安装

<Steps>
  <Step>
    ### 克隆仓库

    ```bash
    git clone https://github.com/AstroAir/cognia-next.git
    cd cognia-next
    ```

  </Step>
  <Step>
    ### 安装 workspace 依赖

    ```bash
    pnpm install
    ```

    安装所有 workspace 成员：根包（`cognia-next`）、`docs/`、`mobile/`、`plugin-sdk/typescript/`。仓库根目录唯一 `pnpm-lock.yaml`。

  </Step>
  <Step>
    ### 隐式步骤

    `prepare` 接上 Husky 钩子（commitlint + lint-staged）；`predev` / `prebuild` 把 Monaco 资源拷到 `public/`，并构建 VS Code sidecar。

  </Step>
  <Step>
    ### （可选）安装 sidecar 依赖

    Node sidecar 位于 `sidecar/`，**不在** workspace 内（独立 lockfile，作为 Tauri 资源打包）：

    ```bash
    pnpm sidecar:install
    ```

  </Step>
</Steps>

## 在 Web 模式下运行

```bash
pnpm dev
```

在 [http://localhost:3000](http://localhost:3000) 启动 Next.js 开发服务器。适合：

- 不依赖 Tauri API 的 UI 开发。
- 写测试。
- 快速迭代，不必承担 Rust 编译开销。

Web 模式下，`invoke()` 调用都被 `isTauri()`（`lib/tauri.ts`）守护，在浏览器中变 no-op。Twin 设置中的原生向量库选项也会被隐藏（仅保留云端后端）。

## 在桌面模式下运行

```bash
pnpm tauri dev
```

并行运行 `beforeDevCommand: pnpm dev`，然后编译并启动 Tauri 窗口。首次编译需要几分钟（下载并编译约 300 个 Rust crate）；之后只需几秒。

窗口弹出即表明安装无误。从这里你可以：

- 调整大小、拖动、最小化 —— 窗口状态由 `tauri-plugin-window-state` 持久化。
- `Ctrl/Cmd+Q` 干净退出；sidecar 由 `src-tauri/src/lib.rs` 的生命周期处理器关闭。
- 在系统托盘菜单中打开 DevTools（仅 debug 构建）。

## 验证工具链

```bash
pnpm tauri info
```

会报告：

- Tauri CLI 版本、Rust 版本、操作系统信息。
- 所需 Tauri 插件是否齐全。
- WebView2 / WebKitGTK 版本。

若有 ❌，先解决再继续。

## 首次常见问题

<Accordions type="single">
  <Accordion title="`Cannot find module 'collections/server'`" id="collections-server">
    文档包需要 `pnpm docs:dev`（或 `pnpm docs:build`）跑**一次**，由 fumadocs-mdx 生成 `docs/.source/`。没有这个目录，TypeScript 无法解析 `docs/lib/source.ts` 中的 `collections/server` 别名。

    ```bash
    pnpm docs:dev   # 保持运行，或首次编译完后 Ctrl+C
    ```

  </Accordion>
  <Accordion title="Sidecar 启动失败（无凭证）" id="sidecar-credentials">
    Sidecar 从 Claude Code 同样的源读取凭证（`ANTHROPIC_API_KEY`、`~/.claude/` 中的 OAuth token）。全新机器上若未登录 Claude Code，sidecar 仍能启动，但每个 `claude_send` 都返回 "no credentials"。

    二选一：

    - 在 `.env.local` 设置 `ANTHROPIC_API_KEY`，**或**
    - 跑一次 `claude login`（官方 Claude Code CLI）以填充 `~/.claude/`。

  </Accordion>
  <Accordion title="端口 3000 已被占用" id="port-3000">
    <Tabs groupId="os" persist items={["Windows", "macOS / Linux"]}>
      <Tab value="Windows">
        ```powershell
        netstat -ano | findstr :3000
        taskkill /PID <PID> /F
        ```
      </Tab>
      <Tab value="macOS / Linux">
        ```bash
        lsof -ti:3000 | xargs kill -9
        ```
      </Tab>
    </Tabs>

    也可以改成 `PORT=3010 pnpm dev`，并相应修改 `tauri.conf.json` → `build.devUrl`。

  </Accordion>
  <Accordion title="Rust 编译错误" id="rust-errors">
    ```bash
    rustup update stable
    cd src-tauri && cargo clean && cd ..
    pnpm tauri dev
    ```

    <Callout type="warn" title="sqlite-vec 编译失败">
      若看到 `error: failed to run custom build command for sqlite-vec ...`，说明缺少 C 编译器 —— 按上文 "前置要求" 安装平台工具链。
    </Callout>

  </Accordion>
</Accordions>

## 常用脚本

```bash
pnpm dev            # Next.js Web 开发（端口 3000）
pnpm tauri dev      # 桌面开发模式

pnpm build          # 静态导出 → out/
pnpm tauri build    # 桌面安装包

pnpm test           # Jest
pnpm test:coverage  # Jest 覆盖率（≥ 90 % 门槛）
pnpm typecheck      # tsc --noEmit
pnpm lint           # ESLint
pnpm format         # Prettier 写入

pnpm docs:dev       # Fumadocs（端口 3001）
```

完整脚本参考见 [开发](./dev/development)。
