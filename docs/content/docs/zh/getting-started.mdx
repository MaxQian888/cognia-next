# 快速开始

本页带你从一份新鲜 clone 走到一个能跑的 Web 开发服务器**和**一个能弹出窗口的 Tauri 桌面应用。首次运行约需 15 分钟；之后只需几秒。

<TLDR>
  - **三个 workspace**：根包（Next.js + Tauri
  前端）、`docs/`（Fumadocs）、`mobile/`（Capacitor）。一份 lockfile。 - **Node 20+ / pnpm 10.30.x /
  Rust 1.77.2+** 是硬要求。 - **凭证有两条路**：API key（`.env.local` 或 keyring）或 Claude Pro/Max
  OAuth（订阅设置面板内）。 - **第三方依赖**：Node sidecar 有独立 `pnpm install`；首次构建需要
  `docs:dev` 跑一次以生成 `.source/`。
</TLDR>

## 前置要求

| 工具             | 版本       | 用途                                                                |
| ---------------- | ---------- | ------------------------------------------------------------------- |
| **Node.js**      | ≥ 20.x     | Next.js 16 / React 19 运行时                                        |
| **pnpm**         | ≥ 10.30.x  | `package.json` 锁定 `pnpm@10.30.3`，整个 monorepo 共用一个 lockfile |
| **Rust**         | ≥ 1.77.2   | Tauri 2.9 + `cognia-server` headless 二进制                         |
| **C/C++ 工具链** | 因平台而异 | Tauri 编译原生扩展（如 sqlite-vec、`mdns-sd`、`ring`）需要          |

平台特定说明：

<Tabs groupId="os" persist items={["Windows", "macOS", "Linux"]}>
  <Tab value="Windows">
    安装 **Visual Studio Build Tools**（包含"C++ 桌面开发"工作负载）。**WebView2 Runtime** 在 Windows 11 上已自带；Windows 10 请从 [Microsoft Edge WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) 安装。
  </Tab>
  <Tab value="macOS">
    安装 Xcode 命令行工具：

    ```bash
    xcode-select --install
    ```

    Apple Silicon 与 Intel 都不需要其他设置。

  </Tab>
  <Tab value="Linux">
    安装 GTK / WebKitGTK / libsoup，按发行版参见 [Tauri 前置要求](https://tauri.app/start/prerequisites/)。

    Ubuntu / Debian：

    ```bash
    sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
        libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
    ```

  </Tab>
</Tabs>

验证：

```bash
node --version    # v20.x 或更新
pnpm --version    # 10.30.x 或更新
rustc --version   # 1.77.2 或更新
cargo --version
```

## Workspace 拓扑

Cognia 是 pnpm 多包仓库。`pnpm-workspace.yaml` 注册了两个子包，加上根包总共三个：

| 包       | 路径      | 端口 | 角色                                                                                  |
| -------- | --------- | ---- | ------------------------------------------------------------------------------------- |
| 根包     | `/`       | 3000 | Next.js 16 + Tauri 前端（`output: "export"`）                                         |
| 文档站点 | `docs/`   | 3001 | Fumadocs（全功能 server 模式）                                                        |
| 移动壳   | `mobile/` | -    | Capacitor 7 包装器，用 iOS/Android 项目配置（详见 [移动架构](./mobile-architecture)） |

根 `pnpm-lock.yaml` 是唯一锁文件——**所有 `pnpm install` 都从仓库根目录跑**。

## Clone 与安装

<Steps>
  <Step>
    ### 克隆仓库

    ```bash
    git clone https://github.com/MaxQian888/cognia-next.git
    cd cognia-next
    ```

  </Step>
  <Step>
    ### 安装 workspace 依赖

    ```bash
    pnpm install
    ```

    一次性安装**三个包**：根包、`docs/`、`mobile/`。它们共享根目录 `pnpm-lock.yaml`。

  </Step>
  <Step>
    ### 隐式步骤

    首次安装还会执行：

    - `prepare` 脚本 → 安装 Husky git hooks（commitlint 校验 commit-msg、lint-staged 处理 pre-commit）。
    - `predev` / `prebuild` → `node scripts/copy-monaco-assets.mjs`，把 Monaco 编辑器资源拷贝到 `public/`。

  </Step>
  <Step>
    ### （可选）安装 sidecar 依赖

    Node sidecar 位于 `sidecar/`，**不在** workspace 内，因为它会作为 Tauri 资源打包。
    如需直接调试 sidecar，请单独安装其依赖：

    ```bash
    cd sidecar
    pnpm install
    cd ..
    ```

    完整协议详见 [Sidecar & Claude SDK](./sidecar-and-claude-sdk)。

  </Step>
</Steps>

## 在 Web 模式下运行

```bash
pnpm dev
```

在 [http://localhost:3000](http://localhost:3000) 启动 Next.js 开发服务器。Web 模式适合：

- 与 Tauri API 无关的 UI 开发。
- 写测试。
- 快速迭代，不必承担 Rust 编译开销。

Web 模式下，`invoke()` 调用都被 `isTauri()`（`lib/tauri.ts`）守护，会在浏览器中变成 no-op。多个子系统会优雅降级：

- 原生向量库选项在 Twin 设置中会被隐藏（仅保留云端后端）。
- 平台连接器、Companion API、远程控制、MCP HTTP 服务器、工作流 cron 守护进程、订阅 OAuth 都不可用。详见 [运行时 & Tauri](./runtime-and-tauri)。
- 桌面同步源（[同步系统](./sync-system)）也被替换为浏览器内的 stub。

## 在桌面模式下运行

```bash
pnpm tauri dev
```

它会并行运行 `beforeDevCommand: pnpm dev`，然后编译并启动 Tauri 窗口。首次编译需要几分钟（下载并编译约 300 个 Rust crate）；后续只需几秒。

如果窗口弹出，说明安装无误。从这里你可以：

- 调整大小、拖动、最小化 —— 窗口状态由 `tauri-plugin-window-state` 持久化。
- `Ctrl/Cmd+Q` 干净退出；sidecar 由 `src-tauri/src/lib.rs` 中的生命周期处理器关闭。
- 在系统托盘菜单中打开 DevTools（仅 debug 构建）。

### 在移动模式下运行（可选）

```bash
pnpm mobile:sync          # 静态导出 + Capacitor 同步
pnpm mobile:open:ios      # 用 Xcode 打开 iOS 项目
pnpm mobile:open:android  # 用 Android Studio 打开
```

`mobile/` 包通过 Capacitor 把 Next.js 静态导出包到 iOS/Android。运行时通过 LAN 或 Tunnel 连回桌面的 Companion API。详见 [移动架构](./mobile-architecture)。

## 验证工具链

```bash
pnpm tauri info
```

会报告：

- Tauri CLI 版本、Rust 版本、操作系统信息。
- 所需 Tauri 插件是否齐全。
- WebView2 / WebKitGTK 版本。

如果有 ❌，先解决再继续。

## 凭证：API key vs OAuth

Sidecar 启动时需要至少一种 Anthropic 凭证。Cognia 支持两条互斥路径——选哪条都行，但每条都有自己的配置位置。

<Tabs groupId="cred" persist items={["API key", "Claude Pro/Max OAuth"]}>
  <Tab value="API key">
    最直接的方式 —— 把 key 放到 `.env.local`（dev）或环境变量（生产）：

    ```bash title=".env.local"
    ANTHROPIC_API_KEY=sk-ant-...
    # 可选 — 自定义 base URL（兼容 Anthropic API 的代理）
    ANTHROPIC_BASE_URL=https://api.anthropic.com
    ```

    UI 路径：**Settings → System → Providers** 也可以把 key 写进 OS keyring（推荐生产用），不落盘。详见 [提供商系统](./provider-system) 与 [CCSwitch](./ccswitch)。

  </Tab>
  <Tab value="Claude Pro/Max OAuth">
    Cognia 实现了"粘贴码"PKCE 流，使用 Claude Code 公开 client id。流程：

    1. UI 路径：**Settings → System → Claude Subscription**。
    2. 选择 *Subscription* 或 *Console* 模式，复制授权链接到浏览器登录。
    3. 把回调里的授权码粘贴回 UI，Cognia 用 PKCE 兑换成 access + refresh token，存进 OS keyring。
    4. Sidecar 重启时 Rust 侧把 `CLAUDE_CODE_OAUTH_TOKEN` 环境变量喂给子进程（同时主动 unset `ANTHROPIC_API_KEY`）；官方 SDK 自动加 Bearer + `oauth-2025-04-20` beta header。

    完整流程、5h/7d 速率限制可视化、用量采样见 [Claude 订阅 OAuth](./claude-subscription-oauth)。

  </Tab>
</Tabs>

如果两种都没有，sidecar 仍能启动，但 `claude_send` 会返回 `no credentials` 错误。

## 常见首次问题

<Accordions type="single">
  <Accordion title="`Cannot find module 'collections/server'`" id="collections-server">
    文档包需要先运行一次 `pnpm docs:dev`（或 `pnpm docs:build`），由 fumadocs-mdx 生成 `docs/.source/`。没有这个目录，TypeScript 无法解析 `docs/lib/source.ts` 中的 `collections/server` 别名。

    ```bash
    pnpm docs:dev   # 保持运行，或首次编译完后 Ctrl+C
    ```

  </Accordion>
  <Accordion title="Sidecar 启动失败（无凭证）" id="sidecar-credentials">
    Sidecar 从两个来源之一读取凭证：

    - `ANTHROPIC_API_KEY` 环境变量或 Settings → Providers 中写入 keyring 的 API key。
    - Claude Pro/Max 的 OAuth bearer（保存在 `com.cognia.claude-subscription/v1` keyring 条目）。

    Cognia **不**读写 `~/.claude/.credentials.json`——那是 `claude login` CLI 的私有文件。两种登录方式在 Cognia 里完全独立。

    三种解决方案：

    - 在 `.env.local` 设置 `ANTHROPIC_API_KEY`，**或**
    - 在 Settings → Providers 中粘贴 API key，**或**
    - 走 Settings → Claude Subscription 完成 OAuth 流（详见 [Claude 订阅 OAuth](./claude-subscription-oauth)）。

  </Accordion>
  <Accordion title="端口 3000 已被占用" id="port-3000">
    <Tabs groupId="os" persist items={["Windows", "macOS / Linux"]}>
      <Tab value="Windows">
        ```powershell
        netstat -ano | findstr :3000
        taskkill /PID <PID> /F
        ```
      </Tab>
      <Tab value="macOS / Linux">
        ```bash
        lsof -ti:3000 | xargs kill -9
        ```
      </Tab>
    </Tabs>

    也可以改成 `PORT=3010 pnpm dev`，并相应修改 `tauri.conf.json` → `build.devUrl`。

  </Accordion>
  <Accordion title="Rust 编译错误" id="rust-errors">
    ```bash
    rustup update stable
    cd src-tauri && cargo clean && cd ..
    pnpm tauri dev
    ```

    <Callout type="warn" title="sqlite-vec / rcgen / aes-gcm 编译失败">
      如果看到 `error: failed to run custom build command ...`，
      多半是缺少 C 编译器 —— 按"前置要求"安装平台工具链。
      新近引入的 `rcgen`、`axum-server`、`aes-gcm` 也都要本地 C 工具链。
    </Callout>

  </Accordion>
  <Accordion title="`workflow webhook router start failed` 警告" id="workflow-webhook">
    Tauri 启动时会拉起一个 axum 监听器，把端口 0 让 OS 分配给工作流 webhook 路由。
    若端口分配失败或防火墙拦截，会在日志里看到这条警告——不影响 cron 触发器、手动运行、`chat.message` 触发器；但 Webhook 触发器会变成 no-op。
    详见 [可视化工作流](./visual-workflows)。
  </Accordion>
  <Accordion title="`remote-control auto-start skipped`" id="remote-control">
    `remote_control` 模块默认禁用。只有当 `inbound.enabled=true` **且** keyring 还有令牌时它才会启动监听器。fresh install 看到这条信息是正常的——参见 [远程控制](./remote-control)。
  </Accordion>
</Accordions>

## 常用脚本

```bash
pnpm dev            # Next.js Web 开发（端口 3000）
pnpm tauri dev      # 桌面开发模式

pnpm build          # 静态导出 → out/
pnpm tauri build    # 桌面安装包

pnpm test           # Jest
pnpm test:coverage  # Jest 覆盖率（≥90% 阈值）
pnpm typecheck      # tsc --noEmit
pnpm lint           # ESLint
pnpm format         # Prettier 写入

pnpm docs:dev       # Fumadocs（端口 3001）

pnpm mobile:sync    # 同步静态导出到 mobile/ 的 Capacitor 项目
pnpm mobile:open:ios
pnpm mobile:open:android
```

完整脚本参考见 [开发](./development)。
