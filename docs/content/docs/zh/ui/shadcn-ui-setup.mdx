# shadcn/ui 配置

cognia-next 的所有 UI 原子（按钮、对话框、输入框、表格、Sheet、Drawer、Sidebar……）来自 [shadcn/ui](https://ui.shadcn.com/)。这一页是 shadcn 在本仓库的**所有约定与配置**的单一参考：风格选项、已装组件清单、添加新组件的命令、主题 token 与全局 Provider。

## TL;DR

<TLDR>

- 配置文件：`components.json` —— `style: "new-york"`, `rsc: true`, `baseColor: "neutral"`, `iconLibrary: "lucide"`。
- Tailwind 版本 = **v4**（PostCSS 插件，无 `tailwind.config.{js,ts}`，配置全在 `app/globals.css` 的 `@theme inline` 块）。
- **57 个组件**已预装在 `components/ui/`；直接 import，不要再 `shadcn add`。
- 主题 token 用 **oklch 色彩空间** + CSS 变量；亮/暗模式由 `<html>` 上的 `.dark` 类切换。
- `TooltipProvider` 已挂在 `app/layout.tsx`，组件内**不要**再包一层。
- `components/ui/` **不写测试**，**不算覆盖率**（与 `components/ai-elements/` 一样属于 vendored 例外）。

</TLDR>

## components.json

```json title="components.json"
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "new-york",
  "rsc": true,
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "app/globals.css",
    "baseColor": "neutral",
    "cssVariables": true,
    "prefix": ""
  },
  "iconLibrary": "lucide",
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks"
  },
  "registries": {}
}
```

逐项说明：

| 字段                    | 值                | 解释                                                                       |
| ----------------------- | ----------------- | -------------------------------------------------------------------------- |
| `style`                 | `new-york`        | shadcn 的两套官方风格之一（vs `default`），紧凑、稍方一些。                |
| `rsc`                   | `true`            | 默认带 `"use server"` 兼容；组件以 RSC 优先，需要交互则加 `"use client"`。 |
| `tsx`                   | `true`            | TypeScript JSX。                                                           |
| `tailwind.config`       | `""`              | Tailwind v4 无 JS 配置文件 —— 留空让 CLI 跳过该字段。                      |
| `tailwind.css`          | `app/globals.css` | 主样式文件，CLI 注入 `@theme` 时找它。                                     |
| `tailwind.baseColor`    | `neutral`         | 中性灰色板（vs `slate` / `zinc` / `stone`）。                              |
| `tailwind.cssVariables` | `true`            | 用 CSS 变量而非内联 hex，方便换肤。                                        |
| `tailwind.prefix`       | `""`              | Tailwind class 无前缀。                                                    |
| `iconLibrary`           | `lucide`          | `lucide-react` —— 全仓所有图标统一品牌。                                   |
| `aliases.*`             | `@/...`           | 与 `tsconfig.json` 的路径别名一致。                                        |
| `registries`            | `{}`              | 暂不接入第三方 shadcn registry；如要接入自建 registry，加 key 即可。       |

## Tailwind v4 + oklch 主题

`app/globals.css` 顶部三件套：

```css title="app/globals.css"
@import "tailwindcss";
@import "tw-animate-css";
@import "katex/dist/katex.min.css";

@custom-variant dark (&:is(.dark *));
```

Tailwind v4 **无 JS 配置文件**——所有配置直接写在 CSS 里。`@theme inline` 块把 Tailwind utility 映射到 CSS 变量：

```css
@theme inline {
  --color-background: var(--background);
  --color-foreground: var(--foreground);
  --color-card: var(--card);
  --color-card-foreground: var(--card-foreground);
  --color-popover: var(--popover);
  --color-popover-foreground: var(--popover-foreground);
  --color-primary: var(--primary);
  --color-primary-foreground: var(--primary-foreground);
  --color-secondary: var(--secondary);
  --color-secondary-foreground: var(--secondary-foreground);
  --color-muted: var(--muted);
  --color-muted-foreground: var(--muted-foreground);
  --color-accent: var(--accent);
  --color-accent-foreground: var(--accent-foreground);
  --color-destructive: var(--destructive);
  --color-success: var(--success);
  --color-warning: var(--warning);
  --color-border: var(--border);
  --color-input: var(--input);
  --color-ring: var(--ring);
  --color-chart-1: var(--chart-1);
  /* … chart-2..5、sidebar-*、wf-*（workflow 语义）等 */
  --font-sans: var(--font-geist-sans);
  --font-mono: var(--font-geist-mono);
  --radius-sm: calc(var(--radius) - 4px);
  --radius-md: calc(var(--radius) - 2px);
  --radius-lg: var(--radius);
  --radius-xl: calc(var(--radius) + 4px);
}
```

亮色与暗色 token 各一组：

```css
:root {
  --radius: 0.625rem;
  --background: oklch(1 0 0);
  --foreground: oklch(0.145 0 0);
  --primary: oklch(0.205 0 0);
  --primary-foreground: oklch(0.985 0 0);
  /* … */
}

.dark {
  --background: oklch(0.145 0 0);
  --foreground: oklch(0.985 0 0);
  --primary: oklch(0.922 0 0);
  --primary-foreground: oklch(0.205 0 0);
  /* … */
}
```

要点：

1. **单一真理源**：改 `--background`，所有 `bg-background` 跟变。
2. **oklch 而非 HSL/RGB**：在亮/暗下感知一致，避免暗色掉色。
3. **`@custom-variant dark (&:is(.dark *))`**：让 `dark:bg-foo` 在祖先有 `.dark` 时生效；这是基于 class 的暗色模式（不是 `prefers-color-scheme`）。

完整主题流水线见 [主题 & i18n](./theming-and-i18n)。

## RSC 模式与 `"use client"`

`components.json` 的 `rsc: true` 让 shadcn CLI 默认按 RSC 写。但 `components/ui/` 下任何带 hook、事件、useState 的组件文件**第一行**都是 `"use client"`：

```tsx title="components/ui/button.tsx (节选)"
"use client"
// ...
```

实战经验：你自己写的组件如果 import 了 `useState` / `useEffect` / `useContext`，加 `"use client"` 就对了。Server Components 在 `components/ui/` 里实际很少 —— 它们要在 Tauri webview / 浏览器里运行，本质就是客户端组件。

## 全局 Provider 已挂载

`app/layout.tsx` 的 Provider 链已经包含：

- **`TooltipProvider`**（来自 `components/ui/tooltip.tsx`）—— Radix Tooltip 的 root；组件内**不要**再 `<TooltipProvider>` 包一层，否则会嵌套。
- **`Sonner`**（来自 `components/ui/sonner.tsx`）—— toast 容器，业务调 `toast.success("...")` 即可。
- **`SidebarProvider`** —— 用 sidebar 的页面（如 `/settings`）自己挂；不是全局的。

完整 Provider 列表见 [架构](../core/architecture#applayouttsx-的-provider-顺序)。

## 添加新组件（罕见）

预装 57 个已经覆盖几乎所有 UI 需求。**新组件之前先确认它真的不在清单里**——多数时候你需要的"新组件"其实是已装组件的组合或样式 variant。

确认需要新 shadcn 组件时：

<Steps>

<Step>

### 跑 CLI

```bash
pnpm dlx shadcn@latest add <component-name>
```

CLI 会读 `components.json`，按 `new-york` 风格生成文件到 `components/ui/<component>.tsx`。

</Step>

<Step>

### 检查 diff

确认：

- 文件落在 `components/ui/`（不是其他位置）。
- 没有修改 `components.json`（CLI 偶尔多塞字段——回退非必要改动）。
- `package.json` 仅新增了所需的 Radix 依赖。
- 没有改 `app/globals.css` 的 token —— 如有，单独评审。

</Step>

<Step>

### 不要写测试

CLAUDE.md 明确：`components/ui/` 是 vendored，不写测试、不计覆盖率。Jest config 的 `coveragePathIgnorePatterns` 已排除它。

</Step>

<Step>

### 更新本页清单

把新文件加到上面的预装组件表，并简单描述用途，方便后续维护者搜索。

</Step>

## 组合模式：`asChild`

shadcn 组件大量用 `asChild` 把 trigger 行为转嫁给子元素：

```tsx
<Button asChild>
  <Link href="/settings">打开设置</Link>
</Button>

<DialogTrigger asChild>
  <Button variant="outline">编辑</Button>
</DialogTrigger>
```

底层是 Radix 的 `Slot` —— 子元素继承所有 props（含事件 handler、aria-\* 属性），不会包多余 DOM 节点。

## `cn()` —— 唯一的类名合并函数

`lib/utils.ts` 导出 `cn(...inputs)`：

```ts
import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

`clsx` 处理条件类（`condition && "class"`），`twMerge` 解决"两条规则冲突时保留后者"（`p-2 px-4` → `p-2 px-4` 中 `p-2` 的 `px-2` 被覆盖）。

约定：所有组件接收外部 `className` 后用 `cn` 合并：

```tsx
<Button className={cn("rounded-full", className)} />
```

**不要**用模板字符串拼类名 —— 失去 `twMerge` 冲突解析。

## variants：`class-variance-authority`

shadcn 用 [cva](https://cva.style/) 定义 variant：

```tsx title="components/ui/button.tsx (节选)"
const buttonVariants = cva(
  "inline-flex items-center justify-center rounded-md text-sm font-medium ...",
  {
    variants: {
      variant: {
        default: "bg-primary text-primary-foreground hover:bg-primary/90",
        destructive: "bg-destructive text-destructive-foreground ...",
        outline: "border border-input bg-background hover:bg-accent ...",
        secondary: "...",
        ghost: "...",
        link: "...",
      },
      size: {
        default: "h-9 px-4 py-2",
        sm: "h-8 rounded-md px-3 text-xs",
        lg: "h-10 rounded-md px-8",
        icon: "h-9 w-9",
      },
    },
    defaultVariants: { variant: "default", size: "default" },
  }
)
```

要扩 variant，**编辑 `components/ui/<comp>.tsx`** —— 不要在外部 wrap 一层。组件已是 vendored 副本，你拥有完全所有权。

## 图标：lucide-react

`iconLibrary: "lucide"` 决定 shadcn 引入的图标全部来自 `lucide-react`。约定：

```tsx
import { CheckIcon, XIcon, AlertCircleIcon } from "lucide-react"
// 命名以 `Icon` 结尾 —— 与本地组件名区分
```

每个图标默认 24×24px stroke 1.5。常用尺寸：

```tsx
<CheckIcon className="size-4" />   // 16px，按钮内
<CheckIcon className="size-5" />   // 20px，列表项
<AlertCircleIcon className="size-6" /> // 24px，大型提示
```

**不要**用 emoji 图标 —— 跨平台渲染不一致；CLAUDE.md 全局规则也禁止 emoji。

## 暗色模式实战

```tsx
"use client"
import { useTheme } from "next-themes"
import { Button } from "@/components/ui/button"
import { MoonIcon, SunIcon } from "lucide-react"

export function ThemeToggle() {
  const { resolvedTheme, setTheme } = useTheme()
  const isDark = resolvedTheme === "dark"
  return (
    <Button
      variant="ghost"
      size="icon"
      onClick={() => setTheme(isDark ? "light" : "dark")}
      aria-label="Toggle theme"
    >
      {isDark ? <SunIcon className="size-4" /> : <MoonIcon className="size-4" />}
    </Button>
  )
}
```

- 用 `resolvedTheme` 而非 `theme` —— 后者可能是 `"system"`，要拿到实际生效值。
- **不要**自己维护 dark state；`next-themes` 已经在 `app/layout.tsx` 挂好 `ThemeProvider`。
- 关键 token（`bg-background`、`text-foreground`、`border-border`）跨暗色自动切换；无需 `dark:bg-...`。

## 与 ai-elements 的关系

`components/ai-elements/` 是另一组 vendored 组件（来自 [ai-elements](https://www.npmjs.com/package/ai-elements)），跟 shadcn 同等地位：

| 库          | 路径                      | 测试     | 覆盖率 | 修改策略         |
| ----------- | ------------------------- | -------- | ------ | ---------------- |
| shadcn/ui   | `components/ui/`          | 不写     | 不计   | 直接编辑文件即可 |
| ai-elements | `components/ai-elements/` | 不写     | 不计   | 直接编辑文件即可 |
| 业务组件    | `components/<area>/`      | **必写** | ≥90%   | 标准开发流程     |

ai-elements 提供 `Message`、`Reasoning`、`Task`、`Tool`、`Conversation`、`Artifact`、`PromptInput`、`Context` 等聊天高层组件，**底层**绝大多数也是 shadcn 原子（Button、Card、Tabs……）。详见 [聊天 UI 架构](./chat-ui-architecture)。

## 故障排查

| 现象                                          | 原因                                                              | 解决                                                       |
| --------------------------------------------- | ----------------------------------------------------------------- | ---------------------------------------------------------- |
| `cn` 没合并掉 conflict 类                     | 模板字符串拼接绕过了 `twMerge`                                    | 改成 `cn("base", className)`                               |
| Tooltip 控制台报 "TooltipProvider missing"    | 你又包了一层 `<TooltipProvider>`，破坏了上下文                    | 移除你包的那层，layout 已经挂了                            |
| Tailwind class 不生效                         | Tailwind v4 在 `app/globals.css` 寻找 content；新文件路径未被扫到 | 检查文件后缀和路径——`.tsx`/`.ts`/`.mdx` 都被默认匹配       |
| Dark mode 不切                                | `<html>` 上没有 `.dark` 类                                        | 确认 `ThemeProvider` 挂在 layout 顶层，且非 SSR-only       |
| 新 shadcn 组件样式错乱                        | CLI 改了 `components.json` 或 `globals.css`                       | revert 这两个文件的改动，仅保留 `components/ui/<name>.tsx` |
| `Button asChild` 报"Children must be element" | 子元素是字符串/Fragment，不是单个 React element                   | 包一层 `<span>` 或换 `<Button>{text}</Button>`             |
