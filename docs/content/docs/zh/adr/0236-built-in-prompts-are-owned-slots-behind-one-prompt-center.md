# ADR 0236 — 内置提示词是有归属的槽位，统一在提示词中心管理

**状态：** 已接受
**日期：** 2026-10-20
**关联：** ADR-0030、ADR-0090、ADR-0155、ADR-0194、ADR-0198、ADR-0199、ADR-0217、ADR-0237
**设计：** [内置提示词管理](../../../../plans/2026-10-20-built-in-prompt-management.md)（以其第 0 节为准）

## 背景

Cognia 发送数以百计面向模型的文本，散落为调用方旁边的常量，例如：

- 聊天基础提示与人设、模式段落、内置子 Agent 身份；
- 标题与摘要模板、补全与判定提示、团队规划；
- 数字分身、Wiki 与记忆的提炼、Router Fusion 角色；
- 环境初始化 Agent，以及第一方插件的措辞。

用户想要更严格的命令判定、更简短的标题或不同风格的研究报告，只能等新版本。

而用户**已经拥有**的提示词分布在许多界面，规则各不相同：

- 角色（含插件覆盖层与变体）、预设（种子内置项拒绝编辑）、Skill（生成的包）；
- 自定义与插件模式、仓库指令文件、工作区指令、默认系统提示；
- 子 Agent 与团队模板；
- 输入框模板。它们是用户消息，而非指令。

若做成一张字符串表，会给上述每一项制造第二个权威来源，并抹掉它们在运行时的含义。

## 决策

### 一个读取模型，每段文本一个权威来源

`lib/prompts/` 是管理层，在同一模型（`resources.ts`）下列出两类资源：

- **代码槽位。** 内置文本在其使用方旁用 `definePrompt` 声明一次，包含以下字段：
  - 标识：id、类型、分组；
  - 覆盖规则：操作、作用域、生效时机、风险、宿主；
  - 契约：默认正文、变量、必需片段、输出契约、预算、使用方。

  `catalog.ts` 只引用这些定义。出现以下任一情况时目录测试失败：id 重复、默认正文不满足自身契约、定义无人解析。
  覆盖存于带修订的存储（`lib/db/prompt-overrides.ts`），包括：按作用域的绑定（乐观 `rev`）、不可变修订、草稿、重置时的继承墓碑、有界历史。
- **所有者资源。** 所有者适配器（`lib/prompts/adapters/`）通过各所有者自己的服务读写，并声明一次编辑的含义：
  - `source`：原地保存。
  - `custom-copy`：创建变体或副本。内置角色走 ADR-0199 变体；种子预设、Skill、插件模式、种子子 Agent 模板或内置团队模板，复制出保留全部非文本设置的副本。
  - `owner-only`：输入框模板。
  - 校验写入：指令文件。

  适配器绝不保留领域文本的第二个生效副本。

### 解析留在使用方

每个使用方在自己的调用处调用 `resolvePrompt` / `resolvePromptAsync`。解析器的行为：

- 从当前账户的快照中选出最具体的允许作用域（会话、Agent、工作区、账户）。
- 跳过不再满足定义契约或未通过 PII 闸门的覆盖。
- 按预算裁剪 `{{name}}` 的值后渲染。
- 记录最近一次解析供编辑器展示。

以下情况有额外约束：

- **命令判定只能收窄。** 仅当内置判定与自定义判定都认为安全时才自动放行。
- **机器读取的协议文本只读。** 包括循环尾标、A2UI 协议与子 Agent 框架。
- **团队规划** 在每次运行冻结的同一快照上解析。

### 各宿主解析同样的槽位

- **CLI：** `cognia-agent prompts` 在自己的存储中列出、查看、设置、重置、导出与导入。
- **可移植配置：** 在存储之间迁移覆盖。导入时显式映射每个作用域目标，从不信任导出的 id。
- **环境初始化 Agent：** 它以 Rust 或 Bash/PowerShell 脚本运行，因此每个运行时一个槽位（`developer.bootstrap.*`）。
  - 测试固定各槽位默认值与该运行时自带文本一致。
  - 启动器通过各运行时已支持的 `systemPrompt` 字段传入已解析的覆盖；无覆盖时不传，各运行时默认文本逐字节不变。
  - 环境自身的提示词优先于提示词中心的覆盖。
  - 48 KiB 启动预算计入实际发送的提示词。

### 插件声明，宿主赋予权限

插件不能导入宿主代码（ADR-0155），其措辞通过版本化的 SDK 命名空间 `ctx.prompts`（前端、混合与 Python）进入提示词中心：

- **`register`：** 把声明变为 `plugin:<pluginId>/<id>` 槽位。
  - 插件只提供措辞与契约：标题、默认值、变量、片段、契约版本、预算。
  - 作用域、生效时机与风险由宿主赋予。宿主拒绝不满足自身契约的默认值。
- **`resolve`：** 返回会话所在工作区或账户的用户覆盖，否则返回默认值。插件只能访问自己的命名空间。

其他插件贡献：

- **插件子 Agent：** 其提示词是账户作用域的槽位 `plugin:<id>/subagent.<subagent>`，随子 Agent 注册。复制成子 Agent 模板会丢失 `effort` 与 `disallowedTools`，因此不采用。每条派发路径都经同一解析器读取。
- **插件模式：** 与自定义模式一同列出，通过保留工具、权限与输出格式的副本修改。
- **插件停用后：** 槽位消失，覆盖不会消失。覆盖以“不可用”列出，保留在导出中，可删除；插件以兼容契约回归时重新生效。

Deep Research 以此声明其五段系统指令；日期、语言行与其解析的 JSON 结构仍留在代码中。

### 提示词中心界面

设置 → 提示词（桌面与独立 Web）包括：

- **侧栏：**
  - 可按标题、id、描述与内置正文搜索；
  - 按来源、分组、工作区与已修改筛选，按所有者分组。
- **代码详情：**
  - 生效时机、宿主、风险、最近使用、契约、使用方；
  - 作用域目标选择；
  - 变量感知的编辑与实时校验，草稿与发布；
  - 过期编辑与上游变更提示；
  - 与内置文本、已发布文本的对比；
  - 历史与恢复，重置时预览继承文本。
- **所有者详情：** 通过所有者保存；支持自定义副本、“设为默认”、跟随基础版本，以及文件冲突处理。
- **生效预览：**
  - 按发送顺序展示所选 Agent、模式与工作区下新对话的各段；
  - 复用从发送路径抽出的基础提示选择规则；
  - 标注仅在发送时组装的段落。
- **配置导入/导出。**

## 后果

- 内置措辞无需发版即可按账户、工作区、Agent 或会话修改；改错可一键重置，历史保留。
- 每个所有者保持原有语义：
  - 内置项不可变；
  - 文件仍是文件；
  - 变体跟随基础版本；
  - 插件拥有自己的定义。
- 新增面向模型的文本必须声明并在调用处解析。目录测试确保每个声明都有使用方。
- 自 2026-10-20 起，终端 dock 挂载 AI Shell。规划器和错误顾问在调用处解析
  `developer.ai-shell.plan` 和 `developer.ai-shell.error-advisor`；两者均为
  account 作用域的 Prompt Center 槽位，并保留 JSON 响应契约。
- 插件作者获得稳定、无需权限的契约来开放措辞调整，且无法扩大编辑的生效范围。
- 不在范围内：
  - 提供方隐藏提示词；
  - 工具 schema 与授权代码；
  - 配对客户端写入。伴随同步没有配置写入通道，迁移由配置文件承担。
