# ADR 0159 — 划词动作平台

**状态：** 已接受  
**日期：** 2026-08-30  
**建立于：** [ADR-0093](./0093-selection-toolbar-content-hugging-window)、[ADR-0095](./0095-desktop-selection-perception)、[ADR-0153](./0153-the-host-obtains-the-confirmation)

## 背景

ADR-0093 与 ADR-0095 已建立可靠的原生选区观察、内容自适应且不抢激活态的窗口、OCR 信任来源、安全输入框与 URL 闸门、十个内置动作和稳定快捷键。但已有实现中仍有未接线路径：分类结果没有增强输入框提示词，来源信息会丢失，设置页看不到原生健康状态，上下文动作与搜索引擎偏好不可编辑，长选区无法通过动作快捷键触发，插件快捷动作也没有划词入口。

把已登录的插件运行时放进浮层虽能解决发现问题，却会破坏其最小权限设计。让渲染器或插件直接替换外部应用文本，则会把过期预览变成未经审计的输入能力。

## 决策

### 主窗口拥有执行权

原生浮层只接收可序列化、由宿主渲染的动作描述和规范化结果。主窗口负责插件枚举、本地化、权限同意、执行、AI 客户端、PII 闸门、超时和注册表复核。插件在执行期间被禁用或卸载时，结果立即失效。

内置动作、Cognia 改写和插件动作共用一套布局：胶囊最多六个槽位，保留排序、隐藏与置顶 ID，并提供一个宿主渲染的“更多”面板。插件不能在浮层中渲染任意 UI。

### 选中文本必须显式放行

插件快捷动作必须显式选择 `selection` surface。元数据动作只得到来源事实，不得到文本。文本动作必须声明危险权限 `selection:read`，并在每次调用时通过分层同意代理。宿主会再次清洗 URL 元数据，并拒绝畸形或过大的结果。

### 默认先预览；替换由原生端裁决

生成文本和多个版本会显示原文/结果对比、归属、来源警告，以及复制、在 Cognia 中打开、替换和取消。只有新鲜、可编辑、来源为辅助功能的选区才可替换。原生端重新聚焦来源、重读选区、要求文本完全相等，再通过现有的剪贴板恢复粘贴路径执行，绝不降级为未经校验的逐字输入。

直接替换同时要求动作声明和用户逐动作允许列表，并在原生应用矩阵通过前受 `COGNIA_SELECTION_REPLACE=1` 控制。

### 撤销是一份租约，不是历史记录

替换成功后创建短期租约，绑定候选 ID 和物理输入代次。超时、无关输入、焦点或来源丢失、候选变化或已使用都会使其失效。撤销只发送来源应用的原生撤销快捷键。

### 模式、排除与快捷键属于原生职责

`off`、`automatic`、`manual` 取代布尔偏好。网站规则只保存精确主机名或显式通配子域名，并在候选文本发布前检查。功能关闭时仍保留快捷键配置与冲突占位，但只有划词作用域激活时才向操作系统注册。动作快捷键会按需读取当前选区，包括超过自动弹出 4,000 字符阈值的选区。

## 影响

- 浮层继续保持轻量，并可在主窗口隐藏时工作；插件描述与结果仍需要主渲染器存活。
- 权限探测不会弹窗；只有用户点击后才打开系统设置。屏幕录制权限绝不隐式申请。
- OCR、剪贴板、过期、已变化、只读或来源不可用时，只降级到复制/打开，不走更弱的替换路径。
- 只承诺纯文本替换，不宣称保留富文本。
- Contract 1.2.0 与 SDK 0.3.0 为增量兼容；旧插件仍只出现在 palette、composer 与 tray。
