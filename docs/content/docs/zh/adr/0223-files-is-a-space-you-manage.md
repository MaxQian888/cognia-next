# ADR 0223 — “文件”是一个可以管理的空间

**状态：** 已接受。已实现：§1–§7、§10，以及 §9 中的独立模式手机。待实现：§8（工作区文件）和 §9 中的配对模式手机，二者都需要主机端 Rust 改动；上线之前，侧栏没有“工作区文件”分组，配对的手机上没有文件页。
**日期：** 2026-10-10
**相关：** [ADR-0200](./0200-files-is-a-view-that-keeps-what-you-keep)（文件，部分被取代）、
[ADR-0222](./0222-a-conversations-files-are-a-view-and-sharing-them-is-a-grant)（FileSpace 与文件分享）、

## 背景

ADR-0200 把“文件”做成了一个视图：内容仍存放在原处，你可以保留想要的条目。实际用下来，它更像图库，不像能在里面工作的地方：

- 页头的五个标签页把“看哪里”（图片、文件夹）和“怎么看”（最近、收藏）混在一起，两者无法组合；
- “从文件中移除”只是把条目隐藏到源数据下次变化为止，既看不到也撤销不了；文件页自有的上传则被直接删除；
- 所有操作都只能一次处理一个条目：不能多选、不能拖拽、不能重命名、不能复制副本，也不能一次导出多个文件；
- 列表视图没有列，条目的来源和最后活动时间都看不到；
- 模板平台声明了 `document` 域，但背后没有存储；
- Agent 写到磁盘的文件和手机端都不在范围内。

## 决策

### 1. 位置 × 视角

页面新增二级侧栏，列出**位置**：全部、类型分组（文档、产物、图片、视频、上传、工作区文件）、最近、可嵌套的文件夹树、回收站。主区顶部是一排**视角**：推荐、收藏、我的、AI 生成、与我共享。任意位置都能与任意视角组合，只有回收站不受视角影响。

列表视图是一张表，列为：名称、来源（所属对话、“上传”，或对话已不存在时显示“—”）、最后活动、大小、类型；点击表头排序。

ADR-0200 的 `?tab=` 链接会重定向到对应的位置或视角。

### 2. 回收站保留字节 30 天

新增 `libraryItems.trashedAt` 字段（带索引，Dexie v237）。“移到回收站”同时取代原来的“从文件中移除”和“删除”：

- 已进回收站的条目，不会因源数据变化而自己回来；
- 它保留收藏和文件夹，恢复后回到原处；
- 它算作“保留中”，字节保持固定，所属对话被清理时也不会删掉它，因此在保留期内恢复一定能找回字节；
- 恢复时如果文件页之外已经没有任何地方持有它，就把它放进文件夹根目录，使它继续保留。

“永久删除”和 30 天自动清理按同一规则结束条目。自动清理是调度器维护任务 `files-trash-purge`，配对客户端会跳过。规则如下：

| 条目 | 结束方式 |
| --- | --- |
| 文件页自有（直接上传到文件页） | 删除；若仍有对话引用字节，则保留字节 |
| 源仍存在（所属对话还在；在对话之外创建的画布文档也算存在） | 变为“已从文件中移除”（`hiddenAt`），源数据不动 |
| 源已不存在（只有文件页还保留着它） | 删除条目行和固定，由媒体 GC 回收无人引用的字节；成为孤儿的产物或画布行一并删除 |

文件页从不删除其他界面仍在使用的内容。

### 3. 谁创建的，谁分享的

- **我的 / AI 生成** 按创建者区分：
  - 画布文档记录 `createdBy`：从菜单和编辑器创建的为 `user`，由画布工具和插件创建的为 `agent`。旧文档如果是在对话之外或从编辑器创建的，算作用户的。
  - 产物都截取自对话输出，因此算作 AI 生成；例外是独立产物，以及从用户自己的画布派生的产物。
  - 图片按展示它的那条消息的角色判断。
  - 上传文件算作用户的，生成的视频除外。
- **与我共享** 指所属对话是加入的协作投影（`shared:` 开头的 id）的条目。账户自己转换为共享的会话保留原 id，仍算“我的”。

### 4. 推荐是本地打分

分数公式：`exp(-距今/14天) + 0.35·log2(1+对话数) + 0.5·已收藏 + 0.25·本周打开过`。不调用模型；点击表头排序时以排序为准。

### 5. 重命名与复制副本遵从所有权

- 重命名：
  - 画布文档和文件页自有上传直接改源数据（下载时就用这个名字）。
  - 其他类型在条目上记录 `displayName`，源数据保留原标题。
  - ⌘K 用文件页里的名称列出条目，并且不列出已移除或已进回收站的条目。
- 复制副本：
  - 画布文档和产物复制为新的画布文档。
  - 图片、附件和工作区文件复制为文件页自有上传，字节按内容哈希去重。
  - 副本都属于用户。

### 6. 文档模板有了存储

新增 `documentTemplates` 表（Dexie v237），保存用户从画布文档或文件页存下的模板。另有五个内置模板：使用指南、待办清单、项目追踪、周报、会议纪要。它们以代码形式提供，并已本地化。

模板平台的 `document` 域会同时投影这两类模板，该域因此不再是停用状态。文件页在“推荐”顶部以可收起的卡片条展示模板，“新建”菜单里也能找到；选中一个即新建画布文档。模板平台关闭时，这些入口全部隐藏。

### 7. 管理

- 多选：支持范围选择，可批量收藏、移动、移到回收站，或打包成 zip 导出（保留文件夹路径）。
- 拖拽：把条目拖到文件夹或回收站；拖动文件夹改变层级（不能形成循环）；从系统拖入文件即上传。
- 右键菜单与条目菜单内容一致。
- 列表支持快捷键：全选、移到回收站、重命名、上下移动、清空选择。
- 文件夹可以设置颜色和图标，从固定集合中选择。

### 8. 工作区文件

Agent 创建、修改或重命名的文件作为单独一类，按“对话 + 路径”各列一条。数据来自任务工作区账本，账本里没有的由 code-adoption 轮次补上。

- 路径和挂载状态来自对话的 FileSpace（ADR-0222），打开时使用它的 `view=files` 链接，并在打开时检查文件是否还在。
- 文件页从不写入或删除磁盘上的这些文件：重命名只改显示名，回收站是文件页自己的，复制副本会拷贝成文件页自有上传。
- 没有文件系统后端时（纯网页），这一类处于停用状态，并在界面上说明原因。

### 9. 手机

- 独立模式的手机在自己的数据上运行文件页。
- 配对模式的手机通过 `files_library_*` 主机命令读写主机的文件库，字节以 `library-media` 资源按需获取。界面契约因此从 `companion: hidden` 改为 `companion: remote`。

手机布局是列表，长按进入多选，侧栏和预览用抽屉呈现；不支持拖拽和快捷键。

在配对的手机上：

- 这些命令使用设备能力 `client.read` 和 `client.write`，与远程照顾宠物（ADR-0219）一致：成员设备只读，
  所有者设备可写，管理员可以提升成员；
- 打开画布文档或产物时以只读方式预览——文本和图片经 `library-media` 获取，上限 10 MiB，超过时预览提示
  到桌面端打开——来自对话的条目可以跳到手机上的该对话；
- “分享”停用，并提示到桌面端分享：分享策略、协作检查和链接记录都在主机上，而上传较大的选择会超过
  主机桥接 30 秒的超时。

### 10. 分享依托 ADR-0222

分享使用 ADR-0222 的文件快照：一个 `file-bundle` 分享链接，文件以客户端加密、分块的形式上传。对单个项目或在批量操作栏对所选项目点“分享…”，都会通过与对话文件相同的分享对话框和 `createFileShare` 检查生成一个链接，所以文件分享策略、敏感文件逐个确认和服务器的大小限制都原样适用。

- 每个文件在链接中按它在文件库中的位置命名：`/files/<文件夹路径>/<文件名>`，重名时像 zip 导出一样加编号。
- 项目可能来自多个对话，所以上传任何内容之前——在对话框的 `buildPayload` 中、先于不接收对话的 `createFileShare` 检查——会逐个询问项目所属的协作对话是否允许 `files.share`。只要有一个拒绝，整个链接就不会创建；项目引用的共享对话如果已不在本设备上，因为无法询问，也会拒绝。任一回答中最新的组织策略版本会在检查策略之前先加载。链接记录时不带 `sessionId`。
- 链接的短码记录在它携带的项目上（`libraryItems.sharedLinkCodes`）。只要其中某个短码在 `sharedLinks` 中仍然有效（未撤销、未过期），项目上就显示“已通过链接分享”标记。链接本身、密钥和所有者令牌只保存在创建它的设备的 `sharedLinks` 中。
- 回收站中的项目不能分享。

## 影响

- 移除、恢复和清理的含义只有一套规则，由页面、⌘K 和清理任务共用。
- 进入回收站的字节最多会在 30 天内继续计入资产配额。
- 手机端新增一组主机命令和一种二进制资源；配对客户端从不镜像文件页的表。

## 被否决的方案

- **继续用 `hiddenAt` 充当回收站。** 源数据一变条目就会自己回来，这样的东西不能叫回收站。
- **删除对话仍存在的已进回收站的产物或画布文档。** 文件页只是视图，其他界面仍在使用的内容轮不到它删。
- **只在打开文件页时清理。** 用户多久不打开文件页，字节就会被固定多久。
- **为文件新增一种分享类型。** ADR-0222 已经让分享链接可以携带文件，再开一条路径会重复它的限制和加密实现。
