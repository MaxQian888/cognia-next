# 侧聊

侧聊是挂在当前对话旁边的一个小对话。用它来核对相关的事情，比如"刚才那次 grep 找到了什么？"、"是不是这个文件？"，不必在主对话里花一轮，不会给主对话的历史添噪音，也不会打断仍在工作的 agent。

设计参考了 Claude Code 的 `/btw`、Codex app 的 `/side` 和 Cursor 的侧聊。侧聊是桌面端和 Web 端功能，手机 App 不提供。

## 打开侧聊

| 方式                          | 效果                                                                  |
| ----------------------------- | --------------------------------------------------------------------- |
| `/btw <问题>`                 | 打开侧聊并在其中提问。主 agent 正在执行时也可以用。                   |
| `/side <问题>`                | 与 `/btw` 相同。                                                      |
| 不带问题的 `/btw`             | 打开侧聊，光标落在侧聊输入框。                                        |
| <kbd>⌘</kbd> <kbd>;</kbd>     | 打开侧聊并聚焦；在侧聊里再按一次，回到主对话输入框。                  |
| **侧聊**标签页                | 聊天右侧面板里的标签页（新标签页里也有入口）。                        |
| **开旁支追问**                | 在消息里选中文字，这段文字会被引用到侧聊输入框。                      |
| 分支对话框 → **作为本会话的新旁支** | 把对话分支到侧聊，而不是新建一个对话。                          |

Windows 和 Linux 上的快捷键是 <kbd>Ctrl</kbd> <kbd>;</kbd>。侧聊里不提供 `/btw` 和 `/side`，侧聊不能嵌套。

## 侧聊知道什么

侧聊的每一轮都会带上主对话最近的内容作为参考：最近 24 条有内容的消息，最多约 8,000 个字符；每次工具调用压缩成一行（调用了什么、作用于什么，以及结果摘录）。侧聊会被告知这份记录只供参考，它要回答你的旁问，不要接着执行主任务。

上下文是增量发送的。第一轮发送一份快照；之后每轮只发送主对话自上一轮以来新增的内容，没有新内容就不发。主 agent 还在生成的回复会标记为"进行中"，定稿后再发送一次。如果主对话在此期间被编辑、分支或清空，或者侧聊被清空，侧聊会重新收到一份完整快照。这样每一轮侧聊都很便宜，provider 也能复用 prompt cache。

这份记录只发给模型，不会保存进侧聊的消息里，并且和其他所有模型调用一样经过 PII 检查。

## 由哪个 agent 回答

侧聊使用与所属对话相同的 agent 和模型，相同的工作目录和沙箱，相同的工具与技能设置。侧聊不会运行团队或 squad，总是直接回答。

### 默认只读

新建的侧聊是**只读**的：可以读取、搜索和抓取网页，但不能编辑文件、执行命令、使用 MCP 服务器或启动子 agent。侧聊顶部的开关可以切换为**可编辑**，第一次切换时需要确认。可编辑的侧聊获得主对话的权限，不会超过主对话；这个选择按侧聊分别保存。

当对话运行在[外部 agent](./external-agents) 上时，如果该 agent 能强制执行只读（plan）模式，侧聊就以这个模式运行在同一个 agent 上；如果不能，只读侧聊改用内置 agent，并在顶部注明。开启编辑后，侧聊以主对话的权限运行在该外部 agent 上。

## 把回答带回主对话

侧聊里的每条回复都有两个操作：

- **带回主对话**：把回复引用到主对话的输入框，由你编辑后发送。
- **发送到主对话**：直接把引用的回复作为你的消息发送。如果主 agent 正在运行，它会和你手动输入的追加消息一样送达（agent 支持时实时送达，否则排队）。

如果主对话的输入框当前没有打开，文字会保存到该对话的草稿里，提示中会说明尚未发送。

## 管理侧聊

一个对话可以有多个侧聊，面板顶部的切换器会列出它们。每个侧聊都可以重命名、清空（删除消息和已发送的上下文，保留设置）、删除，或**提升**为侧边栏中的普通对话。第一个侧聊被提升后会保留为普通对话，下次打开侧聊时会新建一个。

删除对话时会一并删除它的侧聊。归档对话会保留侧聊，恢复对话后仍可使用。
