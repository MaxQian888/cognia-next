# 账号同步协议 v1

账号同步的字节级规范已迁到服务仓库，与实现它的同步 Worker 和 `@cognia/sync-protocol` 包放在一起：
**[cognia-services：docs/protocols/account-sync-protocol.zh.md](https://github.com/cognia-labs/cognia-services/blob/main/docs/protocols/account-sync-protocol.zh.md)**（[English](https://github.com/cognia-labs/cognia-services/blob/main/docs/protocols/account-sync-protocol.md)）。

[ADR-0215](../adr/0215-one-person-one-encrypted-sync-space-many-writable-hosts) 记录"为什么"，规范记录"具体字节"。各节内容：

| §     | 主题                                             |
| ----- | ------------------------------------------------ |
| 0–3   | 不变量、原语、标识符、设备密钥与纪元密钥         |
| 4–5   | 签名的设备登记表与设备加入（六位确认码、恢复）   |
| 6–7   | 会话、实时更新，以及签名并填充的操作日志         |
| 8–9   | 快照与客户端按字段合并规则                       |
| 10–15 | 大文件、租约、计数器、账号生命周期、配额、自托管 |
| 16–17 | 错误码与冻结的测试向量                           |

应用以 `@cognia/sync-protocol` 的形式、按 `integrations/cognia-services.json` 固定的 cognia-services 提交使用该协议；协议变更先在服务仓库落地。应用侧说明见[账号同步设备登记](../subsystems/account-sync-enrollment)与[账号同步数据](../subsystems/account-sync-data)。
