# Stateful sync inventory (source-inspected 2026-10-07)

| Path                                                                                                        | State owner and durability                                                                               | Existing performance boundary / risk                                                                                                                                                                                                                                                                                                            |
| ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lib/sync/desktop-sync-source.ts`, `handlers/base.ts`, `companion-sync.ts`                                  | Host Dexie delta reader -> target-scoped companion mirror; durable per-table cursors                     | staged/concurrent pulls with dependencies, 200-row apply slices, 500-row message pages; monotonic message revisions and separate deletion cursor preserve edited historical rows. Do not remove yielding or scope assertions.                                                                                                                   |
| `lib/sync/handlers/session-state.ts`                                                                        | Host unread pointers with local durable pending-read optimism                                            | Each slice scans pending/sending queue with scope filter; per-row queue reduce is candidate measured in this report. Pending unread, maximum read watermark and clientSeq ordering are semantic requirements.                                                                                                                                   |
| `lib/sync/host-state-store.ts`, `host-state-service.ts`                                                     | Host lease/generation/sequence authoritative live state; business row + receipt + projection transaction | `listPendingHostStateActions` scans whole action ledger; existing dispatch/broadcast indexes do not cover summaryState, so a naive indexed rewrite loses pending summaries. `listHostStateSessionChannels` materializes whole rows before selecting keys; startup then reads snapshots individually. Neither changed without end-to-end timing. |
| `lib/sync/host-invalidate.ts`, `host-table-invalidation.ts`                                                 | Changes announce table invalidation only on runtime owner                                                | Host 150ms and client 100ms coalescing; preserves data ownership and avoids mirrored rows rebroadcast loops.                                                                                                                                                                                                                                    |
| `lib/sync/session-history.ts`                                                                               | Target-scoped selected-session hydration; host timeline capability negotiation                           | Coalesces in-flight work per scoped session, aborts superseded scopes, pages complete legacy transcript, transactional media refs, marks search index dirty. No global message download used as a replacement.                                                                                                                                  |
| `lib/sync/tombstones.ts`                                                                                    | Explicit deletion evidence, independent from streaming replacement churn                                 | Indexed deletion-time range then table filter; 90-day retention; session cleanup transaction rechecks recreated parents/media. Changing cursor/filter or deleting evidence can resurrect data.                                                                                                                                                  |
| `lib/db/mobile-outbound-queue.ts`, `lib/queue/outbound-queue.ts`                                            | Durable client actions, scoped queue claims, idempotency and replay                                      | Ordered/leased dispatch with deadlines/retry/deadletters. Queue summary currently materializes and sorts five status groups; scope filtering is required, so blind indexed count is not equivalent.                                                                                                                                             |
| `lib/tauri/resync-coordinator.ts`                                                                           | Event-domain authoritative snapshot recovery                                                             | Dedupe selected resolvers and concurrent resolution; cannot replace failed history recovery with cursor advancement.                                                                                                                                                                                                                            |
| `lib/collab/shared-chat-sync.ts`                                                                            | Remote shared-chat service -> scoped local event/projection cursor                                       | Serialized per database/endpoint/org/session; bounded remote event paging, projection owns applied cursor, explicit revocation purge. Separate from HostState authority and personal account-sync.                                                                                                                                              |
| `lib/collab/sync.ts`                                                                                        | Server-owned issue, membership, workspace, activity mirrors                                              | Read-through caches and scoped pulling; source-inspected mapping only, no remote timing.                                                                                                                                                                                                                                                        |
| `lib/issues/sync/runner.ts`, `engine.ts`, `field-clock.ts`                                                  | Workspace provider synchronization, bindings and field clocks                                            | Independent GitHub/Lark provider I/O and conflict logic; not benchmarked.                                                                                                                                                                                                                                                                       |
| `lib/webdav/sync-now.ts`, `lib/data/destinations/sync-now.ts`, `lib/subscription/sync/subscription-sync.ts` | Explicit snapshots/backups and encrypted subscription-vault snapshots                                    | Distinct from live HostState and account row synchronization; network/storage destination measurements needed.                                                                                                                                                                                                                                  |
| `lib/account-sync/data/*`                                                                                   | Account encrypted row-op synchronization                                                                 | Root agent owns measurement; preserve multi-writer clocks, revision-aware ack, tombstones and capture suppression.                                                                                                                                                                                                                              |

Additional local mirrors found: `lib/settings/provider-profile-sync.ts`, `lib/appearance/shell-sync.ts`, `lib/shortcuts/sync.ts`, `lib/tray/sync.ts`, `lib/mcp/sync-coordinator.ts`, `lib/skills/sync.ts`, `lib/claude/sync.ts`. These are configuration/adapter coordination, not interchangeable database replication. No performance claim is made for mapped-only paths.

Relevant decisions read: ADR-0027 (persistent cursors/offline cache), ADR-0116 (single live-state authority and transaction/lease constraints), ADR-0131 (durable inbox relay, idempotency, projection ownership). Current source takes precedence over older ADR implementation descriptions.
