Headless service and companion: `cognia-server` now shuts down gracefully on SIGTERM (Docker, systemd, `kill`), flips the browser-submission switch when it binds the browser listener, boots in degraded mode when the sidecar script is missing, persists push tokens across restarts, and fans out push notifications from its event bus. A paired device holding remote control can now answer approvals for turns the Host started itself (desktop, IM, scheduler), and the "needs input" alert reaches phones attached to a headless Host. Mobile shell: the offline banner reports an unreachable or reconnecting Host, the pair link's pinned fingerprint is enforced, the remote-sessions list reads the synced table and works offline, the web pair recovery screen lists every previously paired Host, four screens respect the top safe area, transport-tier colours are unified, queued draft rejections carry their own label, the paired-hosts sheet shows which Host it is switching to, and the workflow editor offers a rotate hint in portrait. Companion settings: the browser-access and extension cards explain desktop-only instead of vanishing, the server and mDNS cards say when a saved boot preference failed to start, and the server card shows where its TLS certificate lives. The durability CLI and the persistence layer now share one `--to` parser.
