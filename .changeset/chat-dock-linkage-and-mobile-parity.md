Chat right-rail (Context Workbench / artifact dock) linkage and interaction fixes. Panels that declare a preferred width now actually resize the dock — from the activity rail, the group tabs, the overflow menu, and every external reveal (the browser opener, now in the title bar's Views menu, the Edit/Write review bridge, save-to-project) — applied as a high-water mark so it never undoes a width you dragged to, and sized from the arriving panel so the workspace reaches its own 65% cap instead of the artifact one. Leaving the workspace profile now animates back under the compact cap rather than snapping. The Review activity opens on the artifact library instead of an AI-proposal panel that rendered a blank pane when no proposal existed (that panel now explains itself). Mobile reaches parity with the desktop: a dismissed dock stays dismissed instead of throwing a full-height sheet back over the conversation on every new artifact, the unread mark finally has a host, and the mobile top bar gains the dock's only standing entry point. Collapsing the dock now unmounts its contents once it has retracted, releasing Monaco, the resource chat pane, and the process-wide embedded-webview lease a zero-width panel used to hold. Adds reverse linkage from the dock back into the conversation: jump to the message an artifact came from (metadata panel, tab double-click, tab context menu), reference a whole artifact into the composer, and highlight the tab whose source turn is on screen. Also mirrors the focus-mode takeover animation on exit and labels the group-overflow button with the current panel and sibling count.
