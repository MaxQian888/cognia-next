Select several messages in a conversation and act on them together. Tick a message with the checkbox that appears beside it on hover, or choose "Select messages" from its menu. Click or ⇧-click more, ⌘A selects all and Esc ends the mode. The bar at the foot of the conversation then offers four actions. Reference adds them as one chip that you can expand to see or remove individual messages, and each message is still cited. Summarize answers in a panel and splits long material between messages. Copy labels each message with who said it. Save as memory files one draft, and marks it untrusted when it includes someone else's messages from an IM group or shared conversation. Refreshing a combined chip now rereads every message in it instead of only the first.
