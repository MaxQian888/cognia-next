Workflows can raise a notification. Three new nodes send into the notification centre, read it back with the badge counts, and mark a row seen, read, done or snoozed. This is the non-blocking sibling of Request approval: a durable row on the executing host, fanned out by the user's own preferences, that nothing waits for.

It fans out honestly per host rather than declaring a capability it cannot keep. On the cloud brain the toast and push both become the events-plane broadcast that connected companions ingest into their own centres, where local preferences and quiet hours still apply, and the node reports which channels actually fired. Authored action buttons are refused, because a command nothing registered renders a button that does nothing.
