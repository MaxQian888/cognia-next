Members of an organization on a multi-tenant cognia-server can now chat with Cognia from a paired device, using the organization's model key without ever seeing it. These chats have no tools, count against the member's monthly allowance, and stay private to the member. A member whose organization has no key for the model, or whose allowance is used up, gets a clear refusal instead of a reply.
