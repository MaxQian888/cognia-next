A task started from the browser can now be followed to the end without leaving it. The side panel reads back what the task answered — fetched only for the row you expand, capped and flagged when it was shortened — and can stop one that is still running.

Stopping is honest about the one case it cannot serve: while Cognia itself is driving a task, the Host refuses the stop, and the panel says the desktop is driving it rather than reporting that the task could not be stopped. It also refuses every stop while Browser Access is switched off, which is the same rule the switch already applied to submissions: it governs whether a browser may act on this Host at all, not only whether it may send new work.
