Organization owners and admins on a multi-tenant cognia-server can store the org's model API keys and choose which bundled agents members may use, from a paired device (no Host approval needed: the Host checks their live owner or admin role on every change) or with `cognia-server org-credentials` / `cognia-server org-agents`. Keys are never shown again, and members cannot see or change them.
