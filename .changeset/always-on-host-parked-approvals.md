Bots and scheduled tasks on an always-on host now ask before sending messages, using secrets or changing host settings, and allow workspace work without asking only inside a verified sandbox. Each Bot and task can lower these per kind under **When nobody is watching**. A request that needs you pauses the run and notifies your paired phone, where you approve or deny it from the Bots or Scheduled tasks page; nobody answering within 30 minutes denies it, and the wait does not count against the task's timeout.
