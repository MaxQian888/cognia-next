Issue tracker planning model (Dexie v223). Issues gain a parent and sub-issues, blocking dependencies, a due date, an estimate, a cycle or milestone, and external links to other systems. Cycles and milestones are one new table, managed from the rail, filterable, and synced to the phone. The board and list badge blocked, sub-issue progress and due state. The inspector gains a Planning section, the context menu and bulk toolbar gain a Cycle submenu, the `issue.update` agent tool accepts the new fields, and an agent run is refused on an issue with open blockers, naming them.
