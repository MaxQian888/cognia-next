Goals and Conversations pages reworked for desktop and phone. Goals opens on a compact summary, a "Needs you" list for goals awaiting acceptance, and a dense list of open goals; selecting one opens an inspector beside it (or a sheet on narrow windows) with editable objective, controls, the linked conversation and delete. Templates, defaults, the tracker and console preferences live under one Configure tab, stopping a goal asks first, and analytics use status colours. Conversations keeps titles readable at any width with a merged usage column, gets a real phone list with a Select mode, shows each conversation's goal, and table headers now reverse on a second click. On a paired phone, a goal's acceptance verdict, delete, Run again (and template Use), manual Continue, and its completion verifier (choosing one from the desktop's catalog, removing it, and retrying it) now take effect on the desktop instead of only on the phone. The subgoal checklist (generate, check a step, clear) and the `/goal` slash command (status, create, pause, resume, stop, update) on a paired phone now also act on the desktop's goal, with generation using the desktop's model behind its PII gate. A paired phone now also syncs each goal's activity log, so its goal detail shows the Activity timeline and the judge and exit notes, Overview rows quote the latest judge verdict, and `/goal status` lists recent activity, with a goal's events removed when the goal is deleted on the desktop.
