The chat composer is one consistent control strip, and its dormant pieces work. Every toolbar chip — model, thinking, routing, permission, mode, runtime, preset, sandbox, cost, context and the "No API key" warning — now shares one height, radius and padding, keeps its warning colour, and answers a finger on a phone without growing the row. The toolbar folds a control into "⋯" whenever a label would otherwise be cut off, instead of trusting fixed widths. The "No API key" warning is a real, keyboard-reachable button that folds to a key icon on a narrow row. With drafted replies waiting in a platform conversation, the empty send button offers to review them — typing gives it back to Send. A phone-width browser window gets the phone composer (touch-sized send, keyboard folds after sending), and a team room's `@` on a phone lists files, agents and members like desktop instead of a members-only sheet that covered the input. Typing is lighter: a keystroke no longer rebuilds the send and key handlers or re-renders the voice controls, the bands above the box and the attachment row. A saved draft that finishes loading no longer overwrites what you started typing, and the microphone picker only appears when live voice can actually use it.
