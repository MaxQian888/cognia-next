Settings → External Agents now opens on a fleet overview instead of the preset gallery, with a per-agent readiness pipeline (Configured → Runnable → Connected → Routed) that explains exactly why an agent cannot run and offers one contextual next action — enable, inspect, retry, connect, or add a routing rule.

The section gains a unified navigation rail (overview, configured agents with mini readiness dots and quick connect, and the configure destinations) and a tabbed inspector that edits common fields inline through the lifecycle service, so changing a command or timeout no longer requires the full editor dialog. The fleet summary banner is collapsible and stays collapsed across sessions; the deep protocol-specific editor, preset gallery, delegation rules, and host/runtimes pages are unchanged.
