The file editor in the right-side workspace dock now runs the full editor workbench. Every editor group has its own tab strip (split with Cmd/Ctrl+\, focus with Cmd/Ctrl+1/2, drag or "Move to Other Group" between them), the Explorer sits on the left, and the per-file context workbench (AI with reviewable edit proposals, comments, inspect, outline) is mounted as a collapsible right sidebar that remembers whether it was open. The dock toolbar gains an Editor/Review switch with a changed-file count, and zen mode hides it. Files changed or deleted on disk surface as banners with Compare / Reload / Restore, the Problems panel lists markers from the whole workspace even with no file open, and its filter understands text, globs and `!` exclusions. Editor chords no longer leak into the app: Cmd/Ctrl+K V, K Z and Shift+O work inside Monaco, and under the desktop shell Cmd/Ctrl+B, Shift+P, 1 and 2 act on the editor when pressed there instead of toggling the conversation sidebar or navigating away. The editor fits the dock it lives in: the context workbench is sized by the editor's own layout (it folds to its rail, keeps its width while the dock is dragged, and never takes more than 65% of the editor), a dock too narrow for both side panels keeps one open at a time, and the status bar, Problems header and dock toolbar fold low-priority items and switch labels into icons instead of overflowing or wrapping. Indentation and line-ending changes are in the command palette too. On phones the editor gains a touch tab strip, go-to-line, word wrap, font zoom, rendered previews and Go to File / command-palette buttons, and stops offering desktop-only actions. A bundled Material Icon Theme plugin (off by default) can be enabled from Plugins to theme file icons everywhere, including its light-theme and high-contrast variants.
