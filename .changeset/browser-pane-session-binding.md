The browser page and the site publish preview now work on the chat session you have open, instead of silently having none. Previously, on those two surfaces the annotation queue was always empty (even though "Add to queue" still saved the annotation, where it sat unreachable for 30 days), and Developer mode and Browser Adjust could never be opened at all. The comment box also now shows the Esc / Ctrl+Enter shortcuts it has always accepted.
