Mobile conversation list: the long-press sheet now offers the same actions as the desktop row menu, in the same order — mark as unread, branch conversation, copy link, export and share, and move to another workspace join rename, pin, archive, move to folder, handoff and delete. Both lists now share one set of row actions, so a pin, archive, move or delete confirms, undoes, refuses a handed-off conversation and reports a failure the same way on both, and deleting or archiving the open conversation opens the next one on mobile too. Renaming a conversation on mobile no longer saves a half-typed title when Enter picks an IME candidate. Unread counts on desktop conversation rows are now read out as "N unread" by screen readers. In a browser on Linux, where Alt+1…9 switch browser tabs, the rail no longer advertises or binds those shortcuts.
