The desktop proxy setting now actually covers the desktop. Web search, RAG reranking, cloud OCR, remote-agent transports (ACP over WebSocket and SSE, A2A, OpenCode), share links, the MCP registry, outbound webhooks, integration actions, workflow HTTP/OCR/ingest nodes, GitHub plugin previews, the paste-a-URL plugin installer, WeCom media, the Site preview probe and the IP lookup all route through it — each was previously a bare renderer `fetch` that the packaged shell's CSP blocked outright and that ignored the proxy, its bypass list and its keyring credentials even when it did get out. Adds a native streaming bridge so SSE and large downloads work through the proxy at all, a proxy-aware WebSocket for callers outside the connector subsystem, and proxy routing for the sandbox's filtering forwarder, the Companion OIDC/JWKS client, the workspace runtime, and network-capable child processes. Proxy hosts are now validated with a specific message per mistake instead of failing later as an opaque connection error, and IPv6 proxies and bypass entries work: `::1` in the default bypass list had never matched a `[::1]` target, so loopback IPv6 was silently proxied.
