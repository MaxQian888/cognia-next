Reviewing an agent's changes is complete from the dock: an `apply_patch` call shows each file's diff in chat and in its approval prompt, with "Open in review" per file; the review can narrow to the files this conversation changed and ends in a commit box under the list; the modified side of a working-tree diff can be edited and saved (Ctrl/⌘+S) with a check before overwriting a file that changed on disk; files too large to send in full can load the whole file on request; phones use the lightweight diff view; every lightweight diff gains find (Ctrl/⌘+F), side-by-side layout and word-level highlights; chat diff blocks and edit previews render through the same virtualized view; the hunk review follows the diff's current change and offers the same Stage / Discard actions; and artifact version history compares any two versions.
