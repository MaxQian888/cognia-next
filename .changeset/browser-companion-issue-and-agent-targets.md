A page captured in the browser can now be filed as an issue on one of your boards, or handed to an agent as a task, instead of only ever starting a conversation. Filing writes a card with the page's address and records that a browser filed it; handing it to an agent creates the task and starts it through the same path the task board's own Run button takes, so approvals and host requirements apply unchanged.

An agent target only appears on a Host that can actually run one — the scheduler's own capability check decides, so the panel never offers work that would be refused at dispatch. A board is offered only under the workspace it belongs to, because filing does not move an issue between workspaces.

The panel offers no "show the answer" or "stop" on a filed issue or a queued task: neither has a transcript or a running turn, and controls that would refuse are worse than no controls. The link that opens the work in Cognia is still there.
