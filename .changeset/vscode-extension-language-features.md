VS Code extensions' language features now work in Cognia's editors: hover, completion, definition, declaration, type definition, implementation, references, highlights, formatting, code actions, rename, symbols, signature help, inline completions, colors, folding, selection ranges, links, semantic tokens, inlay hints and linked editing reach the extension with the real document, position, context and cancellation, and come back in the shapes Monaco renders. Extensions see open documents, edits and the active editor, can set language configurations and switch a document's language, and diagnostics show even for files opened after they were reported. Call and type hierarchy register but stay inert, since the editor has no view for them.
