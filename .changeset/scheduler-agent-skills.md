Agents can now work with your schedule from any conversation, not just IM. A new scheduler skill family lets the assistant list, inspect, create, amend, pause, run and delete scheduled tasks, covering every kind of agent run (chat, character, skill, goal, plan, squad, workflow, external agent) on cron, interval, one-off and event triggers. Writes need your confirmation and obey your scheduler permission settings.
