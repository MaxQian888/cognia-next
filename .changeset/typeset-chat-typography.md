Markdown typography now runs on shadcn/typeset. Chat turns, plugin READMEs, skill docs and every other `MarkdownRenderer` surface share one rhythm that scales with its container instead of the fixed pixel sizes each element carried before — headings, lists, quotes and inline code all track the surrounding text size, and the whole scale steps up on narrow viewports. Tables gain typeset's wide-block scroller. Cognia's own accents are unchanged: the primary-tinted italic blockquote, the bordered table grid with its filled header, and sentence-case `h6`.
