Recalled memories and mined project claims now carry a three-way verdict on their source chip — helpful, didn't apply, out of date — which feeds the ranking the next retrieval uses. None of the three removes a memory from recall: a vote only moves its ranking, so a mis-click on a control with no undo stays survivable, while correcting or archiving a memory keeps its own confirmed entry point in `/memory`. "Out of date" additionally marks the memory stale, which is a statement about the memory rather than about this turn.
