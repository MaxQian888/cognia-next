Replace the first-run onboarding dialog with a guided full-screen flow that ends in one real, locally-verifiable piece of work. It scans the machine for agent runtimes you already have installed and offers to import their commands, settings and past sessions inline; skips the sign-in step entirely when it finds credentials that already work; and finishes by running a starter task — read a folder, extract text from a screenshot, or summarize a web page — with only the cards whose capabilities were actually confirmed on this device. Onboarding state is now structured rather than a single dismissal timestamp, so an interrupted setup resumes where it left off and a skipped one leaves a "finish setup" reminder that names what is missing. The flow serves the desktop, browser and both mobile modes from one step sequence, absorbing the separate mobile welcome and pairing screens.
