Always-on hosts update themselves: a host follows its owner's release channel, installs a signed release once nothing is running, and goes back to the previous version if the new one does not come up healthy. A new **Host updates** section on the host's device page shows where it is and lets the owner change the channel, turn automatic updates off or update now; the Update Center lists each paired host, and a host on another contract can be updated in one click.
