Org members on a shared Host now see which agent their conversation runs as, why a turn would be refused (agent not allowed, no org key, a model the org does not serve, or a used-up month), and what is left of their monthly allowance, and can start a new conversation with any agent the org allows. Org owners and admins can see each member's monthly token use and set the default and per-member caps from the Host's org models settings.
