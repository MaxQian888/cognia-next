Adds the Model Evaluation Lab: define an evaluation project once, run it against several models or chat configurations, and get a recommendation backed by statistics rather than a single sample. Runs are durable and recover after a restart, adaptive sampling stops early once a difference is decided, judging supports blind review so scores are not anchored by the model name, artifacts are stored encrypted, and a finished run exports as a portable replay bundle. Also available headlessly via `cognia eval`.
