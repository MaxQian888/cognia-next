Keep several artifacts open at once, and save one straight into your project. The chat side panel now shows a tab for each artifact you have open, so you can move between them without going back through the history list — and each tab remembers which panel and width you left it on. Artifacts also gain a "Save to project…" action: the save dialog opens in your project's folder, and once written the file opens right there in the workspace panel, with its diff a tab away. Saving somewhere outside the project still works and reveals the file in your file manager instead.
