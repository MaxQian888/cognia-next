The desktop conversation rail no longer offers, or applies, the direct/team filter. Its guild rows already scope the list to Chats or to one team on every grouping axis, so the facet could only repeat a choice already on screen — and a `kind: "team"` left over from the mobile list emptied the rail with no control anywhere to undo it. The facet stays on the mobile channel list, which has no guild rows, and the stored value is left untouched by the rail so that list keeps it.
