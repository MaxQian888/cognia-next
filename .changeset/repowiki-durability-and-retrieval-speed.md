RepoWiki plugin: fix three durability bugs, speed up retrieval ~7×, and extend the read surface. `indexes.db` saves are now a single transaction (a crash mid-save keeps the previous index instead of losing it), a scan that fails after acquiring a workspace releases the ephemeral clone instead of leaking it, and `SimpleRAG.index()` fully resets prior index state. `repowiki_search`/`repowiki_ask` retrieval is ~7.6× faster via precomputed TF-IDF norms plus an inverted-index candidate set (identical top-k results), unchanged index reloads no longer rewrite the whole snapshot to disk, cold starts no longer re-embed unchanged wiki pages, the dependency graph is built once per scan instead of three times, file ingest and index builds run off the event loop, and `tiktoken` is now a declared dependency so token budgeting uses real counts instead of a chars/4 estimate. New tools: `repowiki_pages` lists a wiki's outline (page ids stay discoverable after a restart), `repowiki_status` reports live/rehydrated state, index readiness, and freshness without building anything, `repowiki_deps` answers "what imports this file" plus entry points/isolated files/import cycles from the persisted dependency graph, and `repowiki_file_chunks` returns the verbatim indexed excerpts of one file. `repowiki_search` gains `scope` (all/code/wiki) and `pathGlob` filters.
