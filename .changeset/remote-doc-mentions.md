Reference Feishu and Google Workspace documents from the chat composer with `@lark:` and `@gdoc:`. Picking one fetches the body and stages it as an attachment, so it flows through the existing redaction, token-count and preview pipeline. Feishu covers docs, wiki nodes, spreadsheets and Bitable using an already-connected Feishu account; Google covers Docs and Sheets through a new read-only Workspace connection in Settings → Connections. Desktop only.
