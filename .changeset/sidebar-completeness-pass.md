Completed the chat page's left sidebar. ⌘B now really toggles it in the web shell (it was advertised in three menus but only ever bound as a native menu accelerator under Tauri), `/` focuses the conversation search from anywhere on the chat route (expanding a collapsed rail first), and ⌘⌥[ / ⌘⌥] step the active conversation through the list's visible order without leaving the composer. Guild rows and the icon column now carry the unread count of the conversations they hide, and both gained a right-click menu — start a conversation in a section without opening it, mark the section read, manage teams. The sidebar's rows became one keyboard widget: a single tab stop with arrows / Home / End moving between them, instead of fifteen tab stops whose arrow keys were quietly stolen by the conversation list below. The navigation block above the list is now bounded and scrolls, so many teams or pinned features can no longer squeeze the conversation list toward zero height.

Fixes: the "rail on the right" preference is honoured on the chat route (the sidebar takes that edge with its own header, correct seam and resize direction, and the icon column stays beside it) rather than silently jumping the navigation to the left; the guild-rail View-menu toggle says when the rail is folded into the sidebar instead of claiming a rail that is not drawn; folder collapse is read straight from the store, so the desktop and mobile lists can no longer overwrite each other's state; and the sidebar's hand-off to global search lands on the Chats tab.

Also: folders can be reordered (the `order` field the list already sorted by was never writable), a folder created from the list opens its name for editing straight away, the selection toolbar can file conversations into a folder, the display menu carries the sort axis beside grouping, Settings → Conversation exposes the custom-icons toggle, and Sites / Mini-Apps joined the navigation catalog — both were reachable from the Go menu but from no sidebar.
