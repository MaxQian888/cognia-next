Run a host-owned external agent from a browser Composer. Picking one from the runtime chip admits the turn against the host's stored configuration, runs it there, and streams the result back over the companion event bus — with permission and elicitation questions arriving in the same dialogs a local agent uses, answerable only by the device that was asked, and auto-denied after two minutes if nobody is there. The turn is addressed by an immutable revision, so a configuration edited mid-flight is refused rather than silently swapped.
