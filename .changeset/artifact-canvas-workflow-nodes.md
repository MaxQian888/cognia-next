Workflows can now create, revise, read and export artifacts, and create and read Canvas documents. Until now an artifact could only be born from a chat turn, so "every Monday, chart last week's numbers and post the picture to the team channel" had no way to be expressed. Export hands the bytes to the next step rather than opening a save dialog, so an unattended run never stops on a prompt nobody is there to answer. Deleting an artifact, and writing into a Canvas document someone may have open, stay out of workflows on purpose.
