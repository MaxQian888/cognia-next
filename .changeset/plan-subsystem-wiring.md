Plan subsystem: connect the built-but-unreachable half of the unified plan hub. Adds a `/plan` command family that makes every plan source usable from chat — `/plan <objective>` decomposes with the planner model, `/plan new <title> | <step> | …` hand-authors one, `/plan from-goal` and `/plan from-team` project an existing goal or team task list, plus `/plan status` and `/plan cancel`. Adds a "write a plan" composer above the input while planning with no plan open. Approved plans that were not proposed by the model in-transcript now run step by step as visible chat turns (in-session execution), with the plan's checklist and current step injected into each turn; the tracker dock's pause / resume / cancel drive it. The plan PII gate is now enforced before any plan text reaches a model, including PII hidden in a tool step's parameters. Fixes `/permissions` and `/permission-mode` cycling into `bypassPermissions`: the cycle now covers only the safe modes (default → acceptEdits → plan), matching the composer chip, while `/permission-mode <mode>` can still select any mode explicitly — and now reaches `auto` and `dontAsk`, which it previously could not.
