Android app: native features work again after startup. Copy and paste (including Paste on the pairing screen and Copy link to message), Share message, the notification permission prompt, and voice input no longer do nothing. Download and Export buttons now open the system share sheet with the file, and Appearance → Export no longer reports success when nothing was saved. Appearance → Import opens the file picker. The mic button asks for microphone permission and says when it is denied or when voice input doesn't start. Turning on system or push notifications first asks Android for permission and explains when the device can't deliver them. Paste now tells an empty clipboard apart from one it couldn't read.
