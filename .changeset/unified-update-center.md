Add a unified Update Center. Settings now has an Updates section that discovers and tracks updates for the desktop app, the iOS and Android apps, the Chrome and Edge companion extensions, the CLI, plugins, skills and character packs in one place, with release channels, staged rollout, skip and postpone, and a signed catalog the client verifies before believing any of it. Every row says who actually performs the install, so a store update is never presented as something Cognia can apply itself. On macOS the desktop update hands off to the signed, notarized download rather than replacing the app in place.
