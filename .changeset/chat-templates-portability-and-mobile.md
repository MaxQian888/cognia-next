Chat templates become portable and reach the phone. A saved template can now be exported as Markdown, imported from a Markdown file, duplicated, or written into the open checkout as `.cognia/templates/<slug>.md` (behind the same Workspace Trust verdict the reader uses, and asking before it replaces a file that is already there). All of it speaks the one format the composer already reads back, so an export can be committed and reviewed like any other file. Templates the current repository contributes are now listed too, read-only, with a one-click copy into your own library that keeps the demoted setup rather than laundering it. Saved templates also appear in the Template Studio catalog, re-projected as they change instead of only at launch, and the whole section is available on mobile at `/me/chat-templates`.
