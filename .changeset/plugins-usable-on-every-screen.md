Every bundled plugin was checked on desktop and phone. Plugin names, descriptions and slash-command descriptions now follow the app language, and searching and sorting the library use the names you see. Toasts and dialogs name plugins in your language too, and the detail pane shows whether a plugin is actually running. A slash command run from the chat home screen now shows its result instead of discarding it. Uninstalling from Discover asks for confirmation first, and the plugin library, detail and dialogs fit phone screens with gentler motion. Plugin exports (reports, PDFs, visualizations) save on mobile and say where the file went. Plugin tools that write or send ask first, tools that read files stay inside the paths they declare, and long-running tools no longer time out at 30 seconds. Prompt templates insert into the composer, demo plugins and the Laya guard stay off until you turn them on, and the E2B sandbox says when it cannot provision. Zhihu publishing runs in a proper dialog, the GitHub Devin bot asks for a repository, PagerDuty no longer files the same incident twice, RepoWiki rescans in the background, the SRE agent labels its demo data, and Strix refuses a risky step it cannot confirm.
