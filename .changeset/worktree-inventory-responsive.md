The worktree inventory now works at any width and can create a worktree. It was a five-column table with no narrow layout, so on a phone the action column slid off the end and every control on a row was unreachable. Creating a worktree was also possible from exactly one place, a sheet inside Source Control, which left the Workspace page able to list environments but not make one. The agent team's Worktrees tab now shows actual worktrees alongside the reclaimed agent branches it used to show on its own.
