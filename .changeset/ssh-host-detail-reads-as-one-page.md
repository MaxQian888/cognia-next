The device console lays a machine out by what it can answer, not by the list of questions.

A saved SSH host used to arrive as ten cards. Six of them were a single sentence saying the question did not apply: no capability vocabulary, no grants, no sandbox, no workspace, not addressed by the dispatcher, nothing offered to placement. Those six answers are now one record, in the same words, and the two cards that describe the machine are no longer buried under them.

The SSH card spans the pane, because it holds a record, the forwarding rules and three controls. In half a pane it was a ribbon several hundred pixels taller than the card beside it, and the column under that card was empty for all of them. Port forwarding is now a labelled fact in the same record as the address, the route and the host key, rather than a hand-built block below it, and the sentence about the loopback bind appears only when there is a rule it applies to.

The address and the fingerprint moved into the identity record. They are how a machine is named and how that name is verified, and as a card of their own they held exactly one row on every kind but a remote host.

A shell-only host no longer carries a masthead reading `0` placement dimensions in the colour that means "look at this". It could never have offered one, so the number measured it against a bar it was never on, and with no other stat beside it that lone zero was the whole strip.
