Web shell: the desktop-style top bar is now off by default in the browser — each column draws its own header instead of projecting into a global row. The conversation rail keeps its expanded workspace header (workspace switcher, branch, search, list actions), the chat column header hosts the `toolbar.left/center/right` plugin slots, and the command palette (⌘K/Ctrl+K), ⌘B sidebar toggle, and status bar are unchanged. A new "Show the top bar" switch under Settings → Shell layout → Top bar brings the bar back. Tauri is unaffected — there the bar is the window chrome.
