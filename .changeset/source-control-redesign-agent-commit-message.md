Source Control is easier to read and work in. The header names the repository after its title, and the four unlabelled sync icons are now one labelled button that does what the branch needs (Publish, Pull ↓n, Push ↑n, Sync or Fetch), with every network action and the grouped repository tools in two menus. The change list opens at a fixed 340px column that keeps its width as the window resizes. The commit box gains a Generate button, on by default, that writes the message with the agent selected in the composer: Codex, Claude Code and other local agents read the repository in read-only plan mode, a paired host's agent runs on the host, and the built-in agent uses the utility model. The message streams in and can be stopped, and anything already typed is kept as a hint. The commit button now says how many files it commits.
