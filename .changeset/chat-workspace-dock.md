Add a dual-mode chat dock with a real project workspace alongside Artifacts. Conversations linked to a project can edit files with Monaco, browse and search the workspace, review the repository-wide Git diff with per-hunk actions, and jump into files or review from a compact chat changes card. The card reports real staged, unstaged, and untracked line totals and offers an explicit confirmation flow for discarding the repository's current changes.
