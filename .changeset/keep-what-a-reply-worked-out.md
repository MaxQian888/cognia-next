Keep what a reply worked out, as a pending memory draft.

An assistant turn's action bar gains "Save as memory". It files the reply's prose as a private pending draft — never straight into recall — and promotion stays with the existing review flow.

The pipeline behind it was already written, PII-gated and complete, and had never been called from anywhere in the app. Tool output is deliberately left out of the draft: a reply that read a file should not file that file's contents as something to remember about you.
