Devin changelog parity batch. Tool-scoped lifecycle hooks (PreToolUse, PostToolUse, PostToolUseFailure, PermissionRequest, PermissionDenied) now carry `tool_provenance` (`{kind, source, declared_by}`) identifying which surface and artifact declared the tool — a builtin tool, a plugin, an MCP server, or an external agent — so hook policies can gate by tool origin; a new opt-in `tool-provenance-guard` builtin hook consumes it via `COGNIA_DENY_TOOL_PROVENANCE` selectors. Skills discovery now scans `.cursor/skills` (project and `~/.cursor/skills`) with realpath deduplication. `disabledTools` in CLI config suppresses tools by name across every runner. Trigger policies gain a `regex` rule kind validated against an RE2-safe subset. Command safety resolves `cd`/`pushd`/`popd` prefixes so `cd / && rm -rf ./etc` fails closed, and diffs/transcripts render faster via tail truncation and streamed transcript reads. Ships a bundled PagerDuty plugin: verified `incident.*` webhooks (multi-signature `v1=` HMAC key rotation), brokered incident actions, and a handler-executor on-call responder Bot that triages incidents and posts findings as notes after approval. Bot-bound action calls are now scope-generic: actions declare `scopeSelectors` and the broker enforces them against installation-declared scopes (`repository` config or `config.scopes`), so non-repository integrations like PagerDuty bind without a repo scope while GitHub's repository enforcement is unchanged.
