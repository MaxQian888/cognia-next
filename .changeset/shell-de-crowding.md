Shell de-crowding: before you typed a character, the desktop main window mounted 65 interactive controls across its five chrome bands — title bar, guild rail, chat header, composer toolbar and status bar — plus a tab strip that rendered for a single conversation. It now mounts 32 with no control removed — every demoted control moved to the one surface that owns its concern. The chat header drops from six icon buttons to two (⚙ and the artifact dock; Insights became a row in the session sheet, the browser opener moved to Views, the agent-flow switch already existed in the sheet) and from two title rows to one. The composer toolbar drops from twelve inline controls to four: the model chip now carries its effort level inside its own picker, the permission chip stays, and sandbox / agent mode / external agent / runtime / plugin slots moved into "⋯"; Skills, Enhance and web search joined attachments under a new `+` menu on the input. The title bar's four panel-toggle buttons merged into a single Views menu that also inherited theme, language and zoom from the status bar, and the pet / OCR / clipboard quick actions and the duplicate account button are off by default. The guild rail ships three pins (Inbox, Workflows, Agent Teams) instead of eleven, with the rest one click away under "More". The status bar keeps ambient status only: its sidebar toggle and permission picker were duplicates of live controls, and its session name and shell badge ("Desktop" / "Web") were restatements, so those four readouts are gone rather than relocated. The attention panel, the tab strip and the composer's shortcut hints now render only when they have something to say.

Two fixes came with it: the native View menu gained **Toggle Right Sidebar** and **Toggle Terminal**, which on macOS had no menu entry at all, and the session settings sheet now offers every permission mode — its local list had silently omitted `dontAsk` and `auto`.

Existing installs are migrated (`cognia-ui` persist v3) and see a one-time note explaining where the moved controls went; anything you had customised yourself is preserved, and every hidden segment can be switched back on from Views.
