Composer command and memory fixes, plus new input-box assistance. Multiple slash commands now work on a single line when the whole line is commands (`/compact /clear`); a line containing any other word still treats the rest as arguments, so `/review src/a.ts` is unchanged. Starting a message with `!` or `#` no longer kills the `/` and `@` popovers for the rest of the message, and those prefixes now claim only their first line (matching what the popover has always previewed) and are decided from the original input, so `/clear` followed by a line beginning with `!` no longer executes a shell command. `/memory` with an unrecognised subcommand now shows usage instead of silently discarding the message. The `#` prefix reaches long-term memory: the picker offers the two ADR-0069 store scopes alongside the two `CLAUDE.md` file scopes (file scopes are marked desktop-only), a bare `#note` repeats the last destination, and writes go through the same PII gate and consolidator as `/remember`. Failed commands in a multi-command batch are now reported instead of swallowed. Adds a command queue bar (numbered, removable pills for a staged batch, with failure state), a persistent argument-hint bar for the command being edited, a shortcut cheatsheet on `?`, and transcript markers for the previously silent `/clear` and `/permission-mode`.
