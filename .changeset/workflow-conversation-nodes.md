Workflows can work with conversations. Seven new nodes start, read, list, append to, rename, archive and export a conversation. Starting one goes through the same entry point the New Chat button uses, so a conversation a workflow made is the same kind of object as one you made, and reaches your phone through the sync that already carries every other one.

Starting a conversation no longer has to steal your screen. Until now every caller activated unconditionally, which is right for a handoff you asked for and wrong for a scheduled run at 3am or a run on a cloud host with no UI at all. The row, its workspace, its execution context and its announcement all still happen either way.

There is no delete node. Removing a conversation you saved is your call, so the family stops at archive, which is reversible.
