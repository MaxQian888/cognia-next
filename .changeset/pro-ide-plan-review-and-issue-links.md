Plans can now hold a review in the editor, and issues link to the code they name. A new `editor_review` plan step shows proposed file contents in the Pro IDE's native diff view and waits for your approval before the plan continues — and where no Pro IDE is available it still asks, carrying the proposal into the dialog as text, so a plan written on the desktop keeps working elsewhere. Separately, an issue that mentions a file path in its title or description now offers an "Open in Pro IDE" button that jumps straight to that file and line.
