Halve the Traces channel's IndexedDB work, add per-trace export, and make the timeline keyboard-navigable. The channel used to scan the same time window twice per update — once for the trace list, once for the stats bar's own live query — and fold it twice, for one screen; the list now folds both out of a single read, so the headline numbers and the rows below them come from literally the same pass. That read is capped at the newest 20 000 spans with the true window size shown alongside it, so an all-time window on a heavy install is bounded and says what it left out. In the timeline, the per-span Radix tooltip is replaced by one shared hover card and the blocks are memoized with per-lane stable callbacks, so hovering re-renders nothing; blocks moved to a roving tabindex with arrow / Home / End navigation, which also collapses a 400-span trace from 400 tab stops to one per lane. Searching the trace list is now deferred so typing stays responsive over a large window. New: a trace can be copied or saved as raw span JSON or as OTLP through the same converter the otlp-http transport streams, with an option to strip content previews before it leaves the machine — and plugins get the same serializer as `ctx.logs.traces.serialize`.
