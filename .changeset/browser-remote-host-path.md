The cloud browser is now reachable from the desktop app when it is connected to a Cognia server, instead of being hidden behind a check for which shell you were in — so the browser profiles and domain grants you configure in Settings finally do something there, and the desktop gains a browser-engine switch in the preview's overflow menu. When the cloud browser is switched on but nothing is available to run it, every surface now says so plainly rather than failing silently, and the agent's "not supported" messages name what would enable the feature.
