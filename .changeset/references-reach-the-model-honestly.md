References staged in the composer now reach the model and the transcript the way they were staged. A first message sent from a new chat dropped every staged chip without a word, and started the conversation with none of the context it was meant to be about. What the composer attaches to a turn (references, web results, review outcomes) is still sent with the message and kept for later turns, but the bubble now shows what you typed, with a folded card naming what was attached. Before, the bubble showed the whole attached block as if you had written it, the conversation was titled after it, and search, edit, quote and copy all picked it up. Editing a message keeps its references. Staging the same record twice updates the existing chip instead of adding a duplicate, and attached references now count toward the large-message confirmation.

Citations now match the references that were actually sent. A reference added from ⌘K recorded none, and a chip removed before sending stayed cited. Team rooms record citations too. `@msg:` and `^` offer results as soon as a turn finishes, rather than only after search has been opened, and no longer list subagent transcripts, asides or archived conversations. Referenced messages keep their line breaks and full length. Messages from the current conversation are described as such. Code blocks inside a reference no longer break out of it, and a same-length edit to a referenced record is now detected as a change. On BYOK providers the model can now see which message a reply answers. Branch summaries use the Agent's model or a headless turn on subscription accounts, pass the PII check, summarize long conversations in full, and say when the preview is only an outline.
