Pro IDE now matches the app: one shared palette resolver drives the DOM, the native shell and the embedded code-server (so the accent override, high contrast and colorblind modes finally reach it), a full workbench colour table paints the title bar, status bar, tabs, terminal, menus and widgets that used to stay stock VS Code grey, and the pane webview is painted in the app background instead of flashing white. Editor preferences, reduced motion and the display language now sync too, and the companion extension gained save-before-turn, diff preview, reveal-in-explorer, terminal and notification support plus push events so "what the user is looking at" stays live without polling.
