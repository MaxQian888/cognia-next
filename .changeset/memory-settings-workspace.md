Rebuild the Memory settings section as a full workspace, so long-term memory can describe its own state instead of offering a handful of switches over a black box.

- **Overview** reports memory health as numbers rather than adjectives: how much is stored, how it splits across sources and provenance, and what the lifecycle jobs last did.
- **Learning** shows what is being written and under which policy, so "why did it remember that" has an answer that is not a guess.
- **Retrieval** states which mode is actually in effect — and says so out loud when your configuration means something other than what the toggles imply, which is where the old panel quietly misled. A recall preview runs a real query against your own memories, so you can see what a configuration returns before committing to it.
- **Maintenance and privacy** gather the destructive controls in one place, behind a confirmation that names what is about to be deleted.

Every panel edits a draft and saves once, with an unsaved-changes bar and a discard. The layout matches the other heavy settings sections, and both panels and controls are fully localized.
