Extend outbound authorization to GitHub writes (ADR-0239 phase 2a). Every GitHub write an agent, workflow, plugin, Bot, Agent Team or `gh` command makes is now checked against the repositories the request authorized, with a reply on the PR or issue it came from counting as the origin thread. GitHub has its own switch in Settings → Security and starts in shadow mode, which records what it would do and changes no write; the report there lists the unattended writes enforcement would hold and lets you allow a repository into a Bot's or a GitHub account's list first, and each GitHub account in Integrations has its own list of repositories writable unattended. Once enforced, an unattended write to a repository nobody allowed waits for approval (pushed to your phone), an Agent Team's stack publish waits for "approve and publish", and a repository you refuse stays refused for the rest of that request. Writes you make yourself with a button are recorded and never held. `gh` commands that write to GitHub now ask in chat instead of being treated as safe, auto mode no longer approves them by itself, and under GitHub enforcement they ask even in bypass mode.
