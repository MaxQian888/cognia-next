Agents can now have variants: create a variant of any agent (including built-in and plugin-pack agents) and it follows its base for every setting it does not change, so fixing the base's prompt or adding a skill reaches all its variants. The agent list badges variants with their base and override count, offers reset and detach, and refuses to delete a base that still has variants. Workspaces can name a default agent (or variant) that new conversations started there begin as.
