Cloud & relay: the remote-access verdict stops over-claiming. A tunnel only counts when it exposes this Host's listener, a relay probe run from a paired phone no longer stands in for the Host's own route out, and a verdict is dropped when the rendezvous URL changes. Turning the tunnel off now asks first when the shared cloudflared child is serving another feature, an advertised overlay address can be cleared after the daemon goes down, an IPv6 overlay address is bracketed in the URLs invitations carry, and the relay state badge is translated.
