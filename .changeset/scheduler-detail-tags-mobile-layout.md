Scheduled tasks: the detail now shows what a task runs (prompt, command, workflow, plugin handler, with names resolved and the stored payload one click away) and leads its outcomes with success rate, run count, average duration and last result. Tags can be added and removed in the task form (templates and composer drafts keep theirs) and the list search matches them, with `#tag` for tags only. On desktop the task list no longer shrinks below a readable width, the host control sits beside refresh instead of taking a header row, the keyboard highlight scrolls into view and the agenda shows three days before "show more". On phones the page splits into Tasks and Activity tabs (stats, outcomes, agenda, recent runs), uses the desktop's compact filter bar, gains a refresh button and duplicate / backfill / dependency-graph actions, drops the row checkboxes that did nothing, and the detail's actions fit on one line.
