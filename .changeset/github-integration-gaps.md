GitHub integration: every GitHub read (issue mirror and import sync, PR observation, stack publishing, project-thread PR watch, PR review) now uses the accounts connected in Settings → Connections before falling back to the `gh` CLI, and reads a GitHub Enterprise repository from its own server with that server's credential (the issue loop, bot publication and the Devin bot included). A GitHub webhook now refreshes the issue board within seconds instead of waiting for the 15-minute poll, and transferred or deleted issues leave the board. PR observation reads every page of reviews, review comments and check runs, so a long review no longer reports a stale "changes requested". Webhooks can be delivered through a public or tunnel URL; personal-access-token accounts get their repository webhook configured for them, and the loopback listener address is never written to GitHub. New webhook events (review comments, comment edits and deletions, assignment changes, milestones, transfers, commit statuses, branch and tag creation and deletion, release creation), with PR conversation comments joining the pull request's inbox thread. New `createIssue` action and read actions (`getIssue`, `getPullRequest`, `getCommitStatus`, `listIssueComments`, `searchIssues`) for workflows. Issues can be published to a bound GitHub repository or Lark tasklist/table from the detail panel, which also shows the GitHub conversation, and a changed assignee now syncs back to GitHub when it is a GitHub user.
