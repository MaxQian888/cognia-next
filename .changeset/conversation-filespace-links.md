Every conversation now has a Conversation files panel in the dock that lists its working directory, other roots, uploads and artifacts, and links can open a conversation's file directly: `cognia://session/<id>?view=files&path=/workspace/…` (or `/?session=<id>&view=files…` in the app), "Copy Conversation Link" in the workspace file tree and on file tool cards, and `cognia open --session <id> --files --path <path>`.
