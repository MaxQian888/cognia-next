Saved SSH hosts now have a Files section on the device console, on the desktop, in a browser and on a phone. Browse the machine, queue downloads and uploads, and watch them in a transfer queue that survives a reload: a paused transfer resumes from what is already on the far end rather than starting over. The browser says out loud that it reaches the whole machine, because SFTP paths are that machine's own and there is no folder limit to enforce.
