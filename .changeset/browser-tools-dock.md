The browser preview's recorder and DevTools readouts now share one collapsible strip at the bottom of the pane, with tabs for Recorder, Console, Network and Developer — and it only appears once you have loaded a page. Before, both sat there permanently and the recorder started expanded, so an empty preview spent about 100px on tools before there was anything to inspect. Developer mode opens in that strip too, instead of competing with element selection for the side panel.
