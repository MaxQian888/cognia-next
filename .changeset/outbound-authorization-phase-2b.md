Extend outbound authorization to browser submissions (ADR-0239 phase 2b). What an agent's browser actions submit to a site (a form, a sign-up, a post), from the built-in Browser Tools, an External Bridge client, a plugin or a workflow browser node, is now checked against the sites the request authorized. On local and remote Chromium the request itself is held while the action runs; in the built-in preview and the extension browser a click, selection, drag or Enter / Space that might submit is checked before it runs. Browser submissions have their own switch in Settings → Security and start in shadow mode, which records what it would do and changes nothing; the report there lists the submissions enforcement would hold and lets you allow a site into the global site list or a Bot's list first. Once enforced, a submission to a site nobody listed asks you on a new dialog at this computer (allow once, allow for this request, refuse), or waits for approval on your phone when nobody is watching, and the browser action waits for the answer; a site you refuse stays refused for that request. The global site list and Bots' site lists are now in effect. Data a page sends in its address (GET), autosave while typing, and WebSockets opened by a page's workers are not checked.
