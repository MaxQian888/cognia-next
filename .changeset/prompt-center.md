Add the Prompt Center (Settings → Prompts): every prompt Cognia ships, from chat and mode prompts to titles, judges, team planning, memory, Router Fusion roles and the environment bootstrap agent, can be compared with its shipped text, edited with live validation, drafted, published for the account, a workspace, an agent or a session, previewed in send order for a new chat, restored from history, reset, and exported or imported as a profile. Prompts you already own (agents, presets, Skills, modes, instruction files, workspace instructions, the default system prompt, subagent and team templates) are edited in the same place through their own owners, with copies for built-in and plugin items. Plugins can make their wording editable through the new `ctx.prompts` SDK namespace; Deep Research's instructions and every plugin subagent's prompt are now editable, and overrides of a disabled plugin are kept and shown as unavailable.
