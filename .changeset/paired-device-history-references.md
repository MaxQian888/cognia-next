`@msg:`, `@prompt:` and `^` on a paired phone or browser now search the host's whole history instead of the recent part of each conversation the device has synced. A picked message, prompt or tool result is read from the host too, so a reference to something the device never downloaded stages its real text, and a staged chip is checked for changes against the host. When the host can't be reached, the picker shows what the device has and says the list is partial.
