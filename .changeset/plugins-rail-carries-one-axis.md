The /plugins left rail now carries exactly one axis. It used to list the four sections and, nested underneath whichever was open, that section's own view switcher — Library's five status filters, Governance's five aggregate views — so the column was navigation and filter at once and Library's filters existed twice over, once in the rail and again as a chip row in the header. Both switchers move up into a new second header tier shared by every section: one `PluginSectionToolbar` that owns the search field, a segmented view control and the section's own tools, keeping a fixed position and a fixed control vocabulary as you move between sections. Library's status segments carry live counts and the ones sitting at zero are dropped — three of the five are empty on a fresh install — while the selected segment always survives so a count falling to zero can't make the current view vanish; the active segment is derived from the filters themselves, so setting a status in the filter sheet lights the matching segment instead of disagreeing with it. Governance also stops repeating its view name as a heading inside the pane and keeps the plugin detail pane instead of taking the full workspace, which only devtools does now.
