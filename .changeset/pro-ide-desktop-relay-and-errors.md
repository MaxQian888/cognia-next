Pro IDE: a Cognia desktop paired to another desktop can now open that desktop's VS Code, after its owner approves the device for the project (approvals are listed and revocable in Settings → Pro IDE). Start-up failures now say what went wrong and what to do in your language instead of showing a raw error, the engine switch shows when agent drive is off and why, a companion host whose managed IDE is switched off still serves VS Code without agent drive (as the desktop already did), and a browser on the same machine opens the workbench without waiting for its first status check.
