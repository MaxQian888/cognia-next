Make the CLI transcript readable. The composer drew no cursor: its caret is a block glyph painted in reverse video, and reversing a FULL BLOCK fills the cell with the background colour, so the caret was being drawn and was invisible on an empty line or at the end of one. Markdown tables in the fullscreen layout had no geometry at all, joining cells with a bare separator and ruling the header by a character count, so no column lined up and a CJK header got a rule half the width of the row above it. Both renderers now draw the same framed, display-width table. A run of protocol status ticks was narrated into the conversation as `External event: tool_call_update`, one visible line each, landing between a reply and the tool cards it was about. And every cell ended with a blank row, so a turn of one-line tool cards and notices spent half the screen on whitespace. Rows now pack against each other and only a paragraph keeps its air, a settled run of file reads folds into one summary row while the turn is still running rather than only after it commits, and every spinner on screen shares one clock instead of each running its own timer out of phase.
