Workflow editor: a workflow now opens as "Saved" instead of "Unsaved changes", clicking a node no longer marks it unsaved or adds an Undo step, and Undo starts disabled on a workflow nobody has edited — only real edits (adding, moving, resizing, connecting, deleting) count. In the Create workflow dialog, pressing Enter in the name field now creates the workflow.
