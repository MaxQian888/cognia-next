Workspaces are complete from one place. The `/workspace` page now lists the workspace's recent conversations (with a New button), its schedules and its context (description, instructions, tags, knowledge). Every stat tile opens what it counts, the Environments tab flags a repository config waiting for approval, and each tab body scrolls on its own, so nothing below the fold is cut off on the desktop. The workspace manager opens on the workspace you came from. "New" is now a draft until you create it. The manager edits a description, tags and workspace instructions, which are now sent with every conversation in that workspace. It archives and restores workspaces in their own group, and asks before closing over unsaved edits. Removing a workspace is refused while one of its conversations is running. Removing the active workspace switches to Default instead of leaving nothing selected, and the removed workspace's schedules follow its conversations instead of disappearing. Default can no longer be removed. Re-opening an archived workspace's folder restores it instead of creating a duplicate. Conversations can be moved to another workspace from the conversation list's row menu. ⌘K no longer hides conversations that belong to no workspace. The repository-config notification opens the Environments tab. Terminal environment variables can be set per workspace. Loading states, narrow-width layouts and confirmations for destructive actions are tidied across the workspace UI.
