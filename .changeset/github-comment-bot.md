New built-in GitHub Comment Bot: allowlisted collaborators with write access can `@`-mention it in issue and pull request comments to ask questions or get a read-only comment review, check task status, cancel, or get help. It works through webhooks or polling, re-checks the author and the comment before answering and before publishing, never answers its own comments, and publishes automatically under an explicit host grant or after approval.
