Cognia Visualize now renders each of its 22 profiles with a real chart family — sign-aware bars, line/area, scatter/map, pie/donut, radar, gauge, metric, timeline/gantt, heatmap, treemap, box, and layered node-link graphs — from one shared SVG builder used by both the artifact preview and the SVG/HTML exporters, instead of drawing every profile as the same horizontal bars. The preview adopts the canonical plugin renderer pattern: theme-aware `currentColor` text (labels no longer invisible in dark mode), localized adaptive data-table columns, a styled validation list, a parse-error card instead of a mount-time throw, and re-render on locale change. The previously dormant `exporters` capability is wired to a real `visualization-report` custom exporter that renders every visualization artifact in the session into one standalone localized HTML report; a new `visualize_list` tool lets the agent rediscover existing artifacts; `visualize_update` now carries the title; all activation registrations are disposed on `deactivate`; and headless/mobile runtime compatibility is honestly marked degraded since the preview panel and save pickers need a UI shell.
