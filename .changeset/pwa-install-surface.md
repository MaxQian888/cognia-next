The web client can now be installed as a PWA from inside the product. Settings → About gains an "Install the app" card (web shell only) that drives the browser's install prompt, shows iOS's manual Share → Add to Home Screen steps on Safari, and explains that the installed app stays a client of your Cognia server — the desktop app remains the host.

The manifest now pins an explicit app `id`, focuses the existing window on relaunch instead of multiplying windows, adds dock-icon shortcuts, registers `web+cognia` protocol handling through the existing deep-link page, and ships wide + narrow screenshots for the richer install dialog (generated by `pnpm screenshots:pwa`).

The service worker precaches a bilingual offline page and serves it for uncached navigations while offline — a standalone window no longer dead-ends on a browser error page — and the installed icon shows an unread badge fed by the same session unread counts as the mobile shell.
