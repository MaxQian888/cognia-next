Conversation sidebar management: the open conversation now always keeps a row in its scope-tree group instead of disappearing behind "Show more"; "Select conversations" (⋯ menu, a row's Select, or Space) enters a selection mode with checkboxes where a click selects instead of opening, and "Select conversations here" on a folder, Chats or squad header selects that whole section (unfolding it and lifting its Show-more cut); the bulk bar is now two rows — count with Select all / Deselect all / Done, then the actions — its pin and read switches show the one direction that applies to the selection (adding bulk "Mark as unread"), and its delete confirm names the conversations it will remove; "Move to folder → New folder…" (row menu and bulk bar) creates a folder, files the conversations into it and opens its name; folder headers answer a right-click with the same menu as their ⋯ button; the no-results state offers Clear search, Search everywhere and one-click widening to message content, archived conversations or all workspaces; the empty archive offers a way back; rows in the Pinned section no longer repeat the pin glyph; pressing Escape to close a menu or dialog no longer drops the selection; and on the bar-less web shell the sidebar's collapse button moves to the sidebar footer (the chat header keeps only the expand button for a collapsed sidebar). Phone app bar: the missing-API-key warning is a tonal chip / red icon in the action cluster instead of a solid red pill beside the title, and a private conversation no longer spends a whole row on a lone lock button — "Share conversation…" lives in the ⋮ menu, and the sharing strip appears only for a shared conversation.
