Shared AI conversations are now a real multi-person surface. A shared chat lives on the collaboration service with an explicit member roster, a single ordered message log, exactly one Agent Run at a time, risk-based approvals, protected attachments and an audit trail — so removing someone takes effect immediately, two people cannot run the same turn twice, and a non-member cannot discover the conversation at all. Local conversations stay private by default and are never shared without an explicit confirmation, and full history is imported only when you ask for it. Connector and Companion writes fail closed against a shared conversation instead of quietly editing the local copy. The feature is off by default and enabled per deployment.
