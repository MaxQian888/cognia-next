Find a node on the workflow canvas from a phone.

Canvas-scoped search has existed since Spotlight shipped, reachable only by Ctrl/Cmd+F, which a touch device has no way to press. The rows, the group breadcrumb and the "go to this node" behaviour now live in one hook that both shells use, so the phone gets a bottom sheet with a real input and thumb-sized rows while the desktop keeps its command dialog. Two entry points on the phone: a top-bar control, and a row in the long-press canvas menu.
