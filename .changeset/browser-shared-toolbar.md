All three browser previews — the desktop pane, the cloud browser and the web iframe fallback — now share one address bar and toolbar, so the cloud browser finally packs its controls away instead of overflowing in the narrow chat panel, and the web fallback gets the same "preview a web page" starting screen with one-click localhost shortcuts rather than a blank area.
