Every way of switching, reconnecting or removing a remote host now asks first while a turn is running; the status bar and Connectivity overview describe the host a desktop is driving instead of "Local"; Settings → Remote hosts gains Disconnect, remove confirmation, connection errors and the device console's wording; adding a host no longer puts a bare URL in the invitation field, the LAN check sees what you paste, and the status-bar switcher offers "Add a host".

Pairing and tunnel help text now points to the current Settings → Connectivity topics (Local host, Pairing) and Connections → Overview instead of the retired "Companion" settings, and the external bridge's workspace access panel reloads its client list when you switch hosts.
