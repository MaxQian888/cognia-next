Remote hosts and SSH hosts become a real cross-shell fleet console. Adding a host now works in a browser and on a phone instead of dead-ending on a desktop-only settings page, `/devices` and `/servers` stop rendering blank on mobile, the current execution host is pinned in the chrome with an explicit switch, an inactive host's worktrees can be read without repointing the whole app at it, an unhealthy host says why and offers a reconnect or a re-pair, a deployed server can be added as a remote host from its own page, and saved SSH hosts appear in the same list as every other machine.
