External agents can switch between their own models and Cognia models inside a conversation: the model picker shows the agent's native models and a "Cognia models" section (or why it is unavailable for that agent), and the choice is stored per conversation and per agent — a built-in model pick is no longer read as a Cognia binding nor overwritten by an agent pick, so switching back to the Cognia agent restores it. Before an agent has listed its own models, the picker offers its default model, so a conversation that began on a Cognia model can always switch back; replies are labelled with the agent that answered instead of the conversation's agent mode. Switching between Cognia models keeps the agent's own history (in-task rebind); switching between native and Cognia hands over the turns the other side has not seen. Kimi Code, Goose, GitHub Copilot CLI, Aider and the OpenCode server join the agents that can run on Cognia models; Cline, Gemini CLI, Cursor, Kiro, Devin, Qoder and Droid are shown as unsupported with the reason. Phones and browsers paired to a Host can run Host-owned agents on the Host's Cognia models, with an "update the Host" message for older Hosts; a headless Host serves the providers in its provider profiles, and `cognia-server profiles credential-set` stores a provider key for them. A new chat without a project can send its first turn to a Host-owned agent from a phone instead of failing with "workspace unavailable". Sandboxed Cognia-model tasks no longer time out at session start because the agent could not resolve its own task home. Also fixes turns that stayed "running" after a failure or restart (open tool calls are closed and orphaned running states settle), the workbench sheet reopening on every launch on phones, desktop shortcut hints in the phone editor's empty state, a "0s" previous-turn duration, and run records saving a wrong start time.
