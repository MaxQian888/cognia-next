Select messages and passages on a phone, and a clearer selection bar everywhere. Long-press a message for two new rows. "Select messages" opens multi-select, where a tap ticks a message and the back gesture leaves. "Select text" opens the message in a sheet where you can select any part of it, then reference, summarize, explain or translate that passage, or the whole message when nothing is selected. A long press no longer also selects a word and raises the system copy menu. The selection bar is now a dark floating pill with Done first, or a card with labelled actions in a narrow window. It animates in and out, and each message's own buttons step aside while you select. Unticking the last message ends selection, and Esc ends it even from an empty composer. Opening a sheet or mode from another sheet no longer closes it the moment it appears.
