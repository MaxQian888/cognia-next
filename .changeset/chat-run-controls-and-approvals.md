Chat run controls and approvals: while a turn runs the composer's send button becomes Stop (mobile and desktop) — the run strip no longer interrupts on tap and is now a compact tab docked on the input showing state, elapsed time, tool count and the newest tool, and a follow-up typed mid-run gets its own quiet send button. The message list snaps to the bottom when you send and keeps following the reply until you scroll up; "Back to latest" only appears when you have scrolled away and no longer overlaps the newest message; the gap above the input is tighter; reasoning rows drop the duplicated "Thinking" label. Tool approvals show one consistent action group (full-width "Allow once" on phones) and display the actual command for agents such as Kimi Code that stream their arguments instead of sending them with the request, never a bare `{}`. An external agent's turn no longer times out while it is working or while you are deciding on an approval — the deadline now measures inactivity. Tapping a file from a tool row opens it in a read-only preview read from the Host (also on phones), with the workbench sheet opening at full height and a phone-friendly task toolbar. On phones the composer, toolbar included, now rides directly above the keyboard with a smooth transition, and the slash/@ popovers stay below the header and scroll instead of running off-screen. The "+" sheet opens skills, web search and room members in place with a back button instead of a separate popover, without popping the keyboard. With an external agent selected, the model picker lists only that agent's own models (reported by the Host after each turn) and the chip shows the agent's model instead of a Cognia one. Error cards are compact and no longer repeat themselves; long tool-row paths scroll inside the row; Read results no longer show every line number twice; the fullscreen code viewer has a single tidy header, theme-consistent backgrounds and no oversized footer. Global search on phones moves its help into the search row and no longer highlights rows while you scroll.
