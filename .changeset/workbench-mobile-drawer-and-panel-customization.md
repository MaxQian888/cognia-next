The workspace panel on phones is now a real drawer: drag the handle between a half-open and a full-height position, swipe it away, and close it with a proper Close button. Android's back button closes it instead of navigating away, the soft keyboard no longer covers the composer in the AI and comments panels, and its buttons meet the 44pt touch-target size. Opening it from a project file no longer left an empty panel behind.

You can also reorder and hide the individual tabs inside each workbench activity now, not just the activity icons — Settings → Shell layout → Workbench. Hiding a tab only removes the tab; the panel stays reachable from the command palette and its keyboard shortcut.

On desktop, the conversation column can no longer be squeezed below a readable width when the artifacts dock and a right-docked terminal are open together. Three layout features that were built but had no interface (split view, panel groups, per-project layouts) are now labelled as planned rather than being silently absent.
