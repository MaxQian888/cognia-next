Platform connectors: wire up several built-but-dormant surfaces. The Slack adapter form now exposes the "Agents & AI Apps" opt-in (`assistantAppEnabled` — typing indicator, suggested prompts, streamed run presentation) and a "History pages per load" cap (`historyMaxPages`, 1–50, default 10); both keys were already read by the adapter factory but had no UI, so the assistant features were permanently off. The Inbox conversation view mounts the "Load earlier messages" bar under the header on channels whose adapter declares `history.fetch` (Slack / Discord / Lark / OneBot). The canned-response picker lists the interpolation variables (`{{contact.name}}` …) as chips that insert the resolved value into the draft. A per-conversation "N pending approvals" chip (`PendingApprovalChip`, backed by a live subscription seam on the HITL approval registry) is available for the conversation header. Removing an adapter — from Settings or the plugin API — now goes through one shared path that purges keyring secrets, prunes the attachment cache, and deletes the row. The four planned platforms (Email / KOOK / LINE / Mattermost) appear in the Add-connector grid as disabled "Planned" cards and render a labelled generic badge in the Inbox instead of a hard-coded abbreviation; the buildable platforms' badge abbreviations moved to i18n.
