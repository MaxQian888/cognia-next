A page captured in the browser can now be run through one of your saved chat templates. The panel offers them alongside "a new task", asks for the values the template declares — prefilled with whatever it was last used with — and the Host renders the body and starts the task from the template's own agent, model and workspace settings. The template's use is recorded and its values remembered, exactly as when it is run from the composer.

A template that needs a file or workspace entity picked through the `@` menu is not offered at all, rather than shown with a field a side panel has no picker for. The template body itself never leaves the Host: the panel only learns which fields to show.
