# Lobe Icons

Selected AI, Web Search, OCR, and coding-agent brand assets vendored from
[Lobe Icons](https://github.com/lobehub/lobe-icons), static SVG package
`@lobehub/icons-static-svg@1.94.0`.

`qoder-color.svg` is vendored from `@lobehub/icons-static-svg@1.95.1`:
[upstream SVG](https://unpkg.com/@lobehub/icons-static-svg@1.95.1/icons/qoder-color.svg).

Only assets referenced by `components/icons/brand-icon.tsx` are included.
